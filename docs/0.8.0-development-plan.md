# CaptureLab 0.8.0 开发与验证记录

日期：2026-10-02。开发分支：`codex/0.8.0`。版本：`0.8.0`，构建号：`12`。

## 已实现范围

- 新增版本化 `.capturelab` 单文件格式，内嵌 PNG 原图、原始逻辑尺寸、标注、画布变换、输出尺寸和创建时间，不保存导入路径和撤销栈。格式版本为 1；未知版本、损坏资源、非法变换和超限文件会拒绝打开。
- 文件菜单及编辑器底部“项目”菜单提供打开／保存项目（Command-Shift-O／Command-Shift-S）；打开图片和拖入文件也接受项目。打包配置声明 Finder 文档类型，应用启动入口接收项目 URL。
- 新历史将预览 PNG 与可编辑项目作为一条记录提交，重开后可继续修改文字、箭头等对象。旧 PNG 历史作为底图打开，不能还原已合成的旧标注。历史卡片标识可编辑项目。
- 历史索引升级为 schema 3，兼容 schema 1／2。两份资源先写入独立版本文件，再在跨进程锁内更新索引；失败不破坏旧版本。并发编辑同一记录会保留分支副本，避免覆盖另一编辑器的更新。
- 原图由撤销快照共享；裁剪、90° 顺时针旋转、水平／垂直翻转只修改文档几何信息，保持标注坐标和资源可编辑。重新打开后的新编辑支持撤销／重做。
- 图片调整菜单支持按宽高或百分比设置输出尺寸，可保持比例。单边最多 32768 像素，总像素最多一亿；项目文件最多 192 MiB，内嵌图片最多 128 MiB。
- 裁剪支持自由／原比例／1:1／4:3／16:9、精确宽高、移动选区、拖角调整、8 点边缘吸附；Return 应用、Esc 取消。精确裁剪尺寸使用输出缩放前的画布像素，界面帮助明确说明。
- 变换后的画布预览与复制、PNG 保存、拖出、置顶和 R2 上传采用同一合成结果；遮挡输出失败时不回退到原图。鼠标操作经逆变换映射回原图坐标。
- 替换文档、关闭编辑器和退出前保存可恢复的项目与预览；写入失败保留编辑内容及撤销状态，允许重试。历史清理同步移除项目与预览；继续编辑后的保留期从最近编辑时间计算。
- 项目保存入口说明其包含遮挡下的原图；普通分享入口只交付合成图片。项目使用 0600 权限的临时文件写入、同步后原子替换。

## 验证结果

- 完整 Xcode、`-strict-concurrency=complete` 和 `-warnings-as-errors`：290 项测试全部通过（原有 268 项，加 22 项回归）。
- 新增覆盖：项目保存／打开与 Retina 资源尺寸、原始路径不落盘、未知版本／损坏资源／非法几何拒绝、0600 原子替换、完成／重启／历史重开、新编辑撤销、写入失败及提交后报错、并发编辑保留、损坏索引恢复、缺失资源、关闭／退出失败重试、过期旧图重新编辑和配对清理。
- 像素与交互覆盖：90° 旋转及翻转方向、变换后裁剪、尺寸变化、比例边界与精确像素舍入、变换后的选中／拖动／箭头创建、裁剪移动／拖角／吸附，以及所有普通输出入口的合成一致性。
- 原有裁剪及历史测试已更新为“保留可编辑标注、通过合成输出验证遮挡”；既有 OCR／上传迟到隔离、PNG 历史并发和渲染失败保护继续通过。
- ARM64／x86_64 Release 严格并发构建通过，部署目标为 macOS 13；主程序和更新辅助程序均检查架构与最低系统版本。
- 合成素材驱动的原生编辑器、变换后裁剪界面在最小 1080 点宽窗口下完成渲染检查；原生鼠标事件测试验证变换后编辑与裁剪操作。
- `git diff --check` 与两个打包脚本的 Bash 语法检查通过。

## 验证边界与发布状态

- 尚未在真实 Intel 或 macOS 13 设备上运行；双架构编译不代表这些设备的运行验收。
- 混合缩放多屏、跨 Space、实际 Finder 双击注册、系统文件面板、真实鼠标拖入／拖出和大项目长时间编辑仍需人工验收。当前有原生事件与几何／持久化自动测试。
- 已完成双架构 DMG、SHA-256 文件及 Ed25519 更新签名的本地准备；挂载验证、ARM 安装副本逐文件校验及 45 秒启动检查通过，启动日志为空。
- 使用既有自签名证书，未启用 Hardened Runtime、未公证；Gatekeeper 评估拒绝，首次运行可能需要手动批准。尚未执行端到端自动更新实机验收。
- 发布已获确认。本记录描述发布前验证，远端发布状态以 [GitHub Release](https://github.com/MoarLiu/CaptureLab/releases/tag/v0.8.0) 为准。

## 本轮代码审查与修复

- 复现了 40000×1 图片可导入但无法自动保存的问题。图片入口现先验证与项目一致的单边／总像素／文件体积限制，再替换当前文档；拒绝输入时保留原有编辑和撤销状态。
- 复现了项目编码器接受超限逻辑尺寸、生成解码器无法打开文件的问题。编码和解码现共享逻辑尺寸约束，编码同时检查 PNG 资源上限和创建时间。
- 复现了裁剪后放大在边缘混入区域外颜色的问题。现先从合成图裁出允许的像素，再执行缩放过滤，阻止裁剪区域外像素进入普通输出。
- 为以上三项加入回归测试；另以实际 NSWindow 关闭操作验证恢复失败阻止关闭、重试成功关闭及原窗口代理转发。
- 再次审查后未发现其他发布阻断问题；代码、测试、文档及脚本均已列入发布清单，包内未发现用户数据、测试素材、密钥或个人构建路径。
