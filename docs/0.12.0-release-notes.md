# CaptureLab 0.12.0

2026-10-24 · macOS 13 或更新版本 · ARM64 与 Intel 独立安装包

- 重整原生菜单栏：按任务分组，图标、动作名称和快捷键对齐，浮层与贴图管理按当前内容出现。
- 统一设置窗口：通用、快捷键、快捷浮层、上传和关于；快捷键就地录制，失败保留原组合，上传草稿在关闭前获得保护。
- 普通区域截图不再显示宽高和比例面板，拖动并松开即可完成；需要固定尺寸时主动选择“精确框选”。
- 精简编辑器：默认单行主工具栏，标注与裁剪时才展开属性；图层可收起，样式和背景细节按需调整，小窗口保留主要结果按钮。
- 识别窗口补齐空白、进行中、无结果和错误状态，并提供重新框选。统一成功反馈，显示快捷键注册、上传配置和更新可用状态。
- “保存图片…”直接打开系统保存面板；“复制并关闭”先保存可编辑历史再交付成品；新导出不再套用另一张图片的尺寸。

已有项目、历史、快捷键、偏好和 R2 配置继续兼容。R2 上传通道实现保持不变。

安装包沿用项目既有自签名证书，未公证；首次运行可能需要在系统中手动批准。Intel 包在本机以 Rosetta 验证，物理 Intel／macOS 13、多屏及完整辅助功能矩阵尚未实机复测。
