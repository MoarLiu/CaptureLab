# CaptureLab 0.13.0

构建 20 · macOS 14 或更新版本 · Apple Silicon 和 Intel 独立安装包

## 更新内容

- 导入多张图层图片时复用已解码的资源，编辑时检查项目体积无需重新编码源图。历史缩略图按需加载并缓存。
- 调整背景和导出设置时保留上一帧预览。应用背景后，点击画布上的「返回编辑」即可继续标注。
- 裁剪时固定对角锚点，图层对齐仅显示命中的参考线。快速连续修改样式可一次撤销，撤销后保留当前工具。
- 从历史卡片和快捷浮层的预览直接拖出图片。贴图可以滚动缩放，并通过右键菜单复制、保存或继续编辑。
- 识别结果支持滚动查看长文本。二维码识别完成后自动复制首条结果，网页链接可从结果窗口打开。
- 通用设置新增登录时启动。上传设置可测试 R2 连接和清除配置，上传重试会重新签名请求。

## 安装与升级

**从 0.12.0 或更早版本升级，需要手动覆盖安装一次。** 0.13.0 更换了更新签名密钥，旧版无法验证这次应用内更新。

1. 从 GitHub Release 下载适合本机的 DMG，Apple Silicon 选择 `arm64`，Intel 选择 `x86_64`。
2. 退出正在运行的 CaptureLab，打开 DMG，将 CaptureLab 拖入「应用程序」并选择「替换」。
3. 打开 0.13.0。后续版本可继续通过应用内更新安装。

应用标识、macOS 应用签名身份及 `.capturelab` 项目格式延续上一版本。macOS 13 请继续使用 [CaptureLab 0.12.0](https://github.com/MoarLiu/CaptureLab/releases/tag/v0.12.0)。

安装包沿用 CaptureLab 的自签名证书，未进行 Apple 公证。首次启动时，macOS 可能要求手动批准。每个 DMG 附 SHA-256 校验文件及用于应用内更新的 Ed25519 签名文件。
