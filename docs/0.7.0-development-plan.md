# CaptureLab 0.7.0 开发与验证记录

日期：2026-10-02。开发分支：`codex/0.7.0`。版本：`0.7.0`，构建号：`11`。

## 已实现范围

- 保存最近一次成功的区域选择，并提供“重截上次区域”。记录显示器 UUID、全局逻辑坐标和像素密度；屏幕移除、布局变化或分辨率变化后拒绝使用旧区域。
- 自有区域选择层支持固定宽高、1:1／4:3／16:9／9:16 比例、锁定比例、方向键微调、Shift 加速、Option 调整尺寸、十字参考线和放大镜。
- 选择层显示逻辑点尺寸与实际输出像素；输出按选区涉及显示器的最高像素密度合成，并限制为 8000 万像素和单边 32768 像素。
- 提供冻结画面后框选模式。普通精确截图在选择确认后隐藏选择层并重新采样，捕获确认时的当前画面。
- 菜单栏、命令菜单和统一截图入口覆盖区域、全屏、窗口、延时、上次区域、冻结框选、直接识字和二维码识别。
- 全局快捷键按动作保存，支持启用／停用、冲突检测、注册失败原因和物理键位记录；注册新组合失败时保留原组合。
- 直接识字识别成功后复制文本；无文字、失败、取消或旧任务迟到时不覆盖剪贴板。二维码去重并按画面顺序展示多个结果供选择复制。
- 语言设置从当前 macOS Vision 支持列表生成，保存用户选择；空选择使用可用的中英文并启用自动检测。

## 验证结果

- 使用完整 Xcode、`-strict-concurrency=complete` 和 `-warnings-as-errors` 执行完整测试，共 268 项通过。
- 新增回归覆盖 Retina 输出尺寸、负坐标多屏区域持久化与失效、直接识别剪贴板保护和任务替换隔离。
- `git diff --check` 通过。

## 尚未人工确认

- 真实 Retina、多显示器混合缩放、负坐标、显示器热插拔和全屏 Space 下的交互仍需人工验收；当前有几何单测和严格构建验证。
- 真实屏幕录制权限、Vision 真实中英文混排、多个真实二维码、非美式键盘和快捷键冲突需在实机确认。
- 安装包与更新签名已生成并完成本地验证。本节记录发布前验证，远端发布状态以 [GitHub Release](https://github.com/MoarLiu/CaptureLab/releases/tag/v0.7.0) 为准。

## 代码审查修复

- 自定义比例在开启锁定时保存，修改宽度或高度时按保存比例推导另一边；移动、微调和输入框回填不改变锁定比例。
- 拖动越过桌面边界时同时约束宽高，保持选定比例。测试覆盖四个方向、负坐标和全部比例预设。
- 删除编辑器工具栏残留的字符快捷键绑定，区域截图统一通过全局实体键位注册触发。
- 混合缩放测试改为实际跨越 1 倍／2 倍显示器的选区；任务替换测试使用可控完成顺序与不同的新旧结果，验证旧请求晚返回不会覆盖新结果或剪贴板。
- Retina 屏幕尺寸改读显示模式的实际像素宽高；合成前校验源图尺寸。本机系统显示信息回归确认 400×300 点对应 800×600 像素，合成回归覆盖 2 倍输出和尺寸不一致拒绝。此项未替代真实截图交互验收。

## 发布准备

- 修复 Intel 打包配置下默认参数调用主线程隔离构造函数的编译错误，将区域存储初始化移到构造函数体内；随后完整严格并发测试 268 项通过。
- 按项目脚本生成 ARM64／x86_64 两份 macOS 13 目标的 DMG，以及各自的 SHA-256 文件和 Ed25519 更新签名，共 6 个资产；校验和见 CHANGELOG。
- 两份 DMG 已只读挂载，核对版本 0.7.0、构建号 11、最低 macOS 13、主程序及更新辅助程序架构、固定签名身份及包内文件清单。
- 包内仅包含必要应用文件与 Applications 链接，没有用户截图、历史、配置、日志、AppleDouble 文件或个人构建路径。验证日志和脚本保存在被忽略的 dist 目录。
- ARM 应用从最终 DMG 复制到验证目录，所有包内文件的 SHA-256 与挂载内容一致，复制后的代码签名验证通过。
- 从 ARM 安装副本直接启动应用，持续运行 45 秒且进程路径核对正确；启动日志未记录错误。此项仅确认启动存活，不代表截图和识别交互已人工验收。
- 使用既有本地自签名证书，未启用 Hardened Runtime，未公证；Gatekeeper 评估拒绝，首次运行可能需要用户手动批准。
