# CaptureLab 0.11.2 发布验收记录

日期：2026-10-23。基线：`0.11.1 / 055467e`。目标：**0.11.2，构建 18，标签 `v0.11.2`**。准备分支：`main`。完整修复依据见 [第三方审查修复记录](review-remediation-2026-10-23.md)。

## 发布范围

- 历史操作使用非阻塞的跨进程锁；忙时保留编辑、历史列表和撤销状态，允许重试。保留关闭／退出前的恢复保护与更新安装取消门槛，增加同进程重入保护。
- 数据根和历史目录 0700，图片、项目、索引与预设创建时即为 0600，并原子提交。迁移旧普通文件权限，跳过资源链接和 Release 目录；失败时保留数据，可主动刷新重试。
- 兼容以符号链接迁移的数据根／历史目录，锁与资源使用解析后的固定目录。锁文件本身仍拒绝符号链接。
- 相同历史快照不重复发布；缩略图按单条资源身份刷新，清理无生产调用的旧图片更新路径及数量常量。
- 普通对象拖动复用解码并限制显示预览像素，松手恢复精确结果。输出预览不经过 PNG 编解码、不隐式提交文字。含马赛克的缩放预览先精确合成再降采样，避免小比例退化；此类场景可能较慢。
- 保留中文上传名的扩展名，增加开发版本一致性检查和统一验证脚本。

项目格式继续为 2，保留格式 1／2 读取。历史恢复保护延续 0.11.1 的语义，不更改用户保留策略。模糊／马赛克仍可能留下可辨认信息，分享前应使用不透明填充覆盖敏感内容。

## 复审后的回归补强

首次 393 项通过后，第三方复审发现目录链接与低缩放马赛克缺口，均已补修。新增回归验证链接数据根下的读取、编辑、预设与退出，以及输出／对象预览在 1、0.5、0.25、0.24、0.1 比例下等于精确效果再缩小的结果；覆盖图层叠加、后续模糊、旋转和背景。另验证主动刷新重试权限迁移、重入不留下 busy 横幅，以及测试筛选参数不传给 build。

## 签名与验证边界

沿用既有本地自签名证书，未启用 Hardened Runtime、未公证、无额外 entitlements。Gatekeeper 评估拒绝，两包首次运行可能需要手动批准；不声称已通过 Gatekeeper。

实机为 Apple Silicon／macOS 27.0.1（26A434）；x86_64 启动使用 Rosetta，不能替代物理 Intel／macOS 13 验证。混合缩放多显示器、Space、真实 R2 上传及本版完整 UI 更新安装流程未实机验证。原 `⌘⌫` 绑定保持不变；当前 SwiftUI 探针未触发真实 Delete 映射，实体键盘激活情况尚未最终确认。

普通图层预览和输出预览各自最多缓存 64 MiB 解码资源，两个实例可并存；这不是进程总内存上限。含马赛克的预览优先精确效果，可能分配完整合成位图。后台历史 I/O、自动重试队列与锁外暂存仍为后续工作。
