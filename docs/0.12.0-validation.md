# CaptureLab 0.12.0 实现与验证记录

更新日期：2026-10-24。实现分支：`codex/0.12.0`。基线：`0.11.2 / 534be3f`。目标版本：**0.12.0，构建 19**。

状态：实现与发布前 UI/UX 打磨完成，用户已于 2026-10-24 确认封版发布。本文记录开发验证；发布包另见 [发布验收记录](0.12.0-release-validation.md)。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 菜单栏 | 使用原生 NSStatusItem／NSMenu，图标、名称、快捷键与子菜单箭头各占原生列；按捕获、打开／历史、窗口管理、应用管理分组 |
| 菜单状态 | 浮层与贴图管理按实际资源出现；穿透贴图的解锁／关闭保留。只把没有可用注册的快捷键报告为不可用，替换失败仍显示有效的旧绑定 |
| 设置 | 单一窗口，侧栏为通用、快捷键、快捷浮层、上传，以及底部关于；Cmd-comma 和对应导航复用同一窗口 |
| 参数默认值 | 普通区域／冻结框选不创建宽高与比例面板；主动“精确框选…”才进入调整后确认的模式，普通模式继续松开鼠标完成 |
| 快捷键 | 每个动作就地录制、清除和显示错误；录制期间已有全局组合转交录制器，不触发截图。Esc、切换分类、失去窗口焦点会取消录制，失败保留旧组合 |
| 偏好与草稿 | 普通偏好即时保存；历史策略独立提交并保留删除确认；上传草稿跨分类保留，关窗／退出时可保存、放弃或取消。失败保持草稿并定位上传页 |
| 编辑器 | 常用五种工具优先，其他工具有带名称的入口；仅显示当前工具相关属性；图层改为可收起侧栏，图片精确变换按需展开 |
| 编辑上下文 | 退出底部常驻三模式切换；图层按钮进入对象操作，其他标注工具回到标注；成品预览有返回编辑入口。图层选中标注可进入对应的标注编辑 |
| 结果操作 | “保存图片…”直接进入系统保存面板，使用当前成品的原尺寸 PNG；“复制并关闭”沿用先恢复保存、后复制、成功才关闭的保护 |
| 导出与背景 | 主动导出默认跟随当前图片尺寸，格式／质量可沿用；调整尺寸主动展开。背景先展示原图／内置／个人样式及预览，自定义和预设管理默认收起 |
| 空态与权限 | 空历史提供开始区域截图的入口；屏幕录制权限失败保留指引，并提供用户主动打开系统设置的按钮 |
| 配置兼容 | 沿用原有偏好键、历史策略、R2 存储与 Keychain 服务、项目格式及个人预设；没有执行重置或数据格式迁移 |

SwiftUI 的旧设置独立窗口及旧菜单栏视图已移除；原文件／编辑／截图／工具菜单的必要命令和快捷键继续可达。R2 服务本体、上传签名和传输实现没有改动；新增的是配置草稿与未配置时进入上传设置的导航。

## 发布前 UI/UX 建议复核与打磨

| 建议 | 核对及处理 |
| --- | --- |
| 顶部占用过高 | 旧版实际为 52+44 点两行，98 点透明占位用于避让，缩放已在第一行。改为 52 点主栏，按工具／选中标注仅在需要时增加 40 点属性行；选择状态约收回 45 点画布空间，保留三个窗口按钮安全区 |
| 样式与图层入口重复 | 样式移入更多工具，主栏保留带动态提示的图层开关；删除侧栏仅有关闭图标的空白行 |
| 保存语义 | 现有实现已经调用系统 NSSavePanel 并仅写用户选定的 PNG，不会覆盖项目。保留“保存图片…”与单独“保存可编辑项目…”；无需改为保存副本 |
| 识别状态 | 原有进行中／复制禁用已存在；补完整的空、进行中、无结果、失败和结果布局及重新框选，不常驻保留用于重试的截图 |
| 启动器说明 | 改为“选择一种截图方式”，与九个动作一致 |
| 反馈 | 原失败为持久错误对话框／关闭错误提示，并非短暂 toast。保留失败保护；统一成功事件、去掉重复回调提示，重复同一动作仍反馈。底栏回归文档信息和进度 |
| 快捷键 | 现有两组覆盖全部已有全局动作；补每行已注册／未设置／不可用状态与错误，不添加没有既有动作支持的第三组 |
| 上传与更新 | 配置卡片内显示状态；按 Access Key ID 是否匹配解释密钥留空；保存与更新禁用原因可读，保留安装／截图门控 |
| 侧栏色块与菜单分隔线 | 彩色分类图标符合用户 CleanShot 参考，不属于菜单单色规范；增强对比度渲染复核。动态菜单分隔线原已位于条件内，没有相邻重复分隔线，保留实现 |
| 马赛克与命令面板 | 没有使用频率证据支持删除常用马赛克；⌘K 已用于裁剪。搜索命令面板涉及新动作注册与交互，作为独立后续功能，不混入本版打磨 |

## 验证结果

使用完整 Xcode、当前 Apple Silicon／macOS 27.0.1。最终执行：

```bash
./script/verify.sh --scratch-path .build/0120
```

- **410 项测试通过，0 失败、0 跳过**；启用 `-strict-concurrency=complete -warnings-as-errors`。相对基线 398 项新增 12 项，现有 UI／工作流检查同步为新界面。
- ARM64 和 x86_64 的主程序及更新辅助程序严格 Release 构建通过；目标 triple 分别为 `arm64-apple-macosx13.0`、`x86_64-apple-macosx13.0`。Mach-O 架构及 `LC_BUILD_VERSION minos 13.0` 已核对。
- 设置的五个分类在 **900×640、760×540** 点、中英文、浅色／深色及两种 NSAppearance 增强对比度下渲染并检查。独立英文运行使用 `-AppleLanguages '(en)'`，实际图片已确认英文布局。
- 全量通过后，英文渲染发现工具胶囊末端轻微裁切；按实际按钮宽度修正后再通过 16 项界面回归、4 项英文编辑器回归及双架构严格 Release 构建。
- 编辑器最小 **900×600** 点的选择／标注／裁剪布局、工具属性切换及 Esc 裁剪取消通过；1080 点窗口的图层、成品、文字样式、背景与导出面板有合成素材的原生渲染记录。
- 区域选择层使用合成冻结帧验证：普通模式只创建选区窗口，精确模式创建选区及参数窗口；取消后窗口清理。另覆盖普通模式鼠标释放完成、精确模式等待 Return、以及新的普通选择不继承比例约束。
- 原生菜单已实际弹出并记录截图；快捷键在独立列，包含图标。捕获中状态、有效旧热键的失败替换、贴图解锁和关闭入口有回归覆盖。
- 上传草稿测试覆盖未提交、分类切换、HTTPS 校验失败保留、保存后规范化、空密钥复用、访问键改变时拒绝复用旧密钥和放弃更改。全部使用临时目录与模拟凭据。
- 退出与更新门槛复审确认：设置草稿可取消退出；原 `requestUpdateInstallation` 在同步退出返回后清除请求，设置门槛先行取消也不会在稍后退出时重放安装。现有恢复失败、取消与安装回滚回归通过。
- 最终代码差异复查与 `git diff --check` 通过；构建和检查产物留在忽略目录。

## 实际应用操作

使用独立 bundle ID 的 Debug 预览包和明确的临时 HOME，打开合成的格式 1 项目完成下列操作。未替换正式安装，也未发起网络上传。

| 操作 | 结果 |
| --- | --- |
| 打开可编辑项目 | 编辑器显示合成图片，常用工具及简化的结果操作可达 |
| Cmd-comma | 打开统一设置，侧栏和当前分类正确 |
| 开始录制后按 Esc | 取消录制，保留设置窗口及旧配置 |
| 为窗口截图录入已有区域组合 | 行内显示“已用于区域截图”，原组合继续保留 |
| 输入合成 R2 Endpoint 后切换分类再返回 | 输入和“有未保存的更改”状态保留 |
| 带草稿关闭、取消关闭、再次关闭并放弃 | 分别保持草稿／窗口和正确放弃；未写入合成凭据 |
| 点击保存图片 | 直接显示系统保存面板；保存结果核对为 PNG、640×360，与合成原图一致 |
| 正常退出预览包 | 进程退出；临时历史保留可编辑恢复文件 |

初次由桌面工具启动预览包时，LaunchServices 没有采用预期的 `LSEnvironment.HOME`；该进程已停止，未计入隔离验收。上述实际操作使用随后显式传入 HOME 的进程，并检查了临时数据目录和退出状态。后续开发预览继续采用显式环境启动。

## 视觉复审中修正的事项

- 侧栏展开会撑高小窗口：在有界画布内提供可滚动侧栏，精确图片参数默认收起；没有放宽最小窗口验证来掩盖问题。
- macOS 27 会自动隐藏原生菜单项图标：核对 SDK 的公开 API，在可用系统显式设置 `preferredImageVisibility = .visible`；旧系统保持兼容路径。
- 新快捷键录制行的旧焦点回调可能取消另一个录制行：回调核对动作身份；隐藏页面不接收输入，切换分类及失焦清理录制状态。
- 历史策略外部更新：无草稿时刷新显示值，有尚未提交的更改时保留草稿。
- 背景界面验证改为注入独立预设存储，最终截图使用临时预设数据；不把个人预设文件作为测试 fixture。

## 验证边界与保留项

- 本机为 Apple Silicon／macOS 27.0.1；物理 Intel、macOS 13、多屏混合缩放、热插拔及全屏 Space 未实机复测。双架构构建和最低系统元数据不替代运行证据。
- 已检查中英文、深浅色、NSAppearance 增强对比度渲染和辅助功能标签；未完成 VoiceOver 人工操作、系统增强对比度／减少透明度的完整实机矩阵。测试没有改动用户的系统设置。
- 真实跨应用文件拖放、多二维码端到端操作及本版从 UI 开始的完整更新安装未重新手工验收；相关数据／几何／任务／更新回归仍通过。
- R2 上传通道保留用户此前的手动可用验证。本版没有更改签名和传输；本轮验证配置保存、导航及模拟请求，不冒称重新执行了真实账户上传。
- 双架构 DMG 的签名、挂载、启动和发布状态在 [发布验收记录](0.12.0-release-validation.md) 单独维护；本记录中的 UI 测试不替代安装验证。

计划中的 A10、A11 保留为部分覆盖，待补全人工与环境矩阵；不把本机开发完成描述为全部实机验收通过。
