# CaptureLab 0.10.0 第三方审查核对与优化

日期：2026-10-03。核对基线：`main @ 803d28e`（0.9.0）；开发版本：0.10.0，构建号 14。两份报告按实际调用路径、既有保护与回归证据合并评估；报告中的严重等级不直接作为修复结论。

## 已落实的必要修复

- **OCR 使用最终图像**：先提交正在编辑的文字，合成图层、标注、裁切／旋转／翻转与背景，再交给 Vision。合成失败直接报错，清空旧结果，不回退原图。标注变更取消正在运行的 OCR，模糊／马赛克变更还会清空已有结果；普通标注的撤销继续保留用户手工校正文字。已发出的上传仍持有当时的固定图像字节。
- **更新与退出共用恢复门槛**：下载完成后只登记一次安装请求；`applicationShouldTerminate` 成功保存当前项目及预览后才启动安装器并返回允许退出。保存失败、安装器启动失败或退出请求未经过此门槛时，清除请求；之后普通退出不会重放更新。原来“保存失败保留编辑器”的保护继续有效。
- **更新期间限制截图入口**：更新检查、确认框、下载与安装请求期间，普通截图、直接识别、滚动截图和截图启动器均忽略新请求；检查失败后恢复。已经开始截图时不能再进入更新检查。
- **委托与图像防御**：后台线程的窗口委托探测安全返回，不执行 `MainActor.assumeIsolated`；截图解码改为可恢复失败；钉图系统图标有文字回退；颜色使用非可选 sRGB 构造；画布源缓存消除强制解包。
- **热键资源清理**：Carbon 资源由独立对象持有，销毁或显式关闭时先移除 C 回调，再注销热键；重复关闭不重复注销。
- **更新传输和安装权限**：下载的初始 URL、重定向和最终响应均要求 HTTPS，主机限定为 GitHub 及明确的发布资产域名，拒绝 URL 凭据和非常规端口。保留 SHA-256／Ed25519 校验。GitHub 403 限流和 429 提供明确说明与打开发布网页按钮。安装前检查父目录和既有锁文件是否可写，并在实际暂存目录的父目录探测写入；不满足权限时保留应用运行并提示手动安装或个人 Applications 目录。

## 已落实的交互和性能优化

- 标注与对象编辑的方向键统一按屏幕方向移动 1 个显示点，Shift 移动 10 点；通过当前显示尺寸和逆变换计算源坐标，适用于缩放、裁切、旋转与翻转。
- Fit 与固定缩放使用同一个滚动容器，保留原生标注画布身份。缩放引起的文字提交在下一主线程轮次发布，避免在 SwiftUI 更新过程中写回绑定；导出与替换仍可同步提交。
- 复用线程安全的 `CIContext`；历史恢复用 ImageIO 属性读取尺寸；后台缩略图直接传递不可变 `CGImage`，不再 PNG 编码后重新解码。
- 编辑预览缓存截至最后一个模糊／马赛克的完整绘制前缀，其上方的普通标注独立绘制。移动上方图元复用缓存；移动下方图元或滤镜本身必须重算，保证遮挡顺序和像素来源正确。此处没有宣称彻底消除大图主线程渲染。

## 第一份报告逐项结论

| 报告项 | 决定与核对结果 |
| --- | --- |
| 截图 `NSImage(data:)!` | 防御修复已完成。PNG 已重编码，所以现有失败概率低，不能直接认定为 P0。 |
| 钉图 SF Symbols 强解包 | 已增加文字回退；常用符号在最低 macOS 13 可用，报告的系统版本崩溃没有复现。 |
| sRGB／颜色强解包 | 颜色构造已改进；系统标准 sRGB 并非可由截图数据控制的任意资源，不属于已证实 P0。 |
| 滚动拼接强解包竞态 | 报告结论不成立：worker 是 actor，相关同步方法没有挂起点；segments 从首帧开始且最后一段不能被删除。现有取消／重置回归覆盖该状态。 |
| 窗口委托后台 `assumeIsolated` | 风险成立，已做线程边界防御，并以后台任务探测委托的方法验证。未宣称已在真实辅助功能／输入法调用中复现崩溃。 |
| 保存失败无法退出 | 当前行为是项目恢复保护，README 已说明。取消退出本身不是死锁；自动丢弃编辑会引入数据丢失。保留保护，修复它与更新安装的交互。以后可单独设计明确的放弃编辑退出入口。 |
| Retina 尺寸严格比对 | 本机缩放显示未复现：逻辑 3008×1692 点，backing scale 2，模式和截图均为 6016×3384 像素。保留配置变化／帧尺寸一致性保护；其他硬件仍需实测。 |
| 滚动窗口查找应 `continue` | 不接受直接跳过遮挡窗口。采集会合成外国窗口像素，筛选是在阻止污染长图；既有窗口筛选测试明确拒绝上层小窗口和外国浮层。被遮挡后停止采集仍能结束保留已接受图像，并非丢弃会话。 |
| 锁定钉图无法鼠标解锁 | 已文档化的鼠标穿透设计，菜单有“全部解锁”。单张穿透窗口的独立解锁入口属于后续交互设计，不改成取消穿透。 |
| `/Applications` 更新权限／跨卷 | 受限安装目录确有失败路径，已增加退出前权限探测与说明；不能假设所有普通用户都无法写 `/Applications`。暂存目录在目标父目录，跨文件系统交换已被现有结构避免。没有添加提权助手。 |
| Finder 多项目打开丢失文档 | 单编辑器确实最终显示最后一个项目，但替换前会保存上一个项目至可编辑历史。新增集成回归验证原项目文件仍在、首个项目对象已保存。报告的直接丢失结论不成立；独立文档窗口属于更大的架构需求。 |
| 热键没有销毁清理 | 资源生命周期风险成立，已修复并覆盖释放／重复关闭。 |
| 每次创建 `CIContext` | 成立，已复用。 |
| 历史恢复解码原图 | 成立，已改为属性读取。原代码逐个遍历，不是永久同时持有全部图片，报告对峰值规模的描述缺少测量。 |
| 缩略图重复编码／解码 | 成立，已消除中间 PNG。 |
| 方向键位移受缩放影响 | 已统一显示点语义，回归验证多种缩放、裁切、旋转、翻转和 Shift 步长。 |
| 旋转文字的编辑框仍水平 | 核实存在；文字提交后输出的旋转正确。暂保留可读的水平输入控件；精确旋转／镜像的 AppKit field editor 需独立验证，不作为本轮崩溃或输出错误修复。 |
| 有滤镜时全图重绘 | 成立，已优化可复用的绘制前缀；下方内容变化仍需重算，后续可评估有界异步预览。 |
| 缩放导致画布重建 | 成立，已保持视图容器身份，并实测原生画布对象不变、未提交文字不丢失。 |
| 红绿灯反复定位／全屏风险 | 静态代码可确认重复定位，报告没有给出全屏或特定系统版本的实际失效证据。保留当前布局，列为窗口外观专项验证，避免未经视觉验证改动标题栏。 |
| 老截图 API | 废弃／现代化建议成立；“频繁权限提醒、黑屏”没有在本轮复现。ScreenCaptureKit 迁移暂列独立工作，需同时保留 macOS 13、冻结框选、跨屏、窗口过滤和权限语义。 |
| GitHub 无鉴权限流 | 限流存在，已改进失败说明和网页入口；检查是用户手动触发，不能据此认定必然经常触限。不在桌面客户端嵌入访问令牌。 |
