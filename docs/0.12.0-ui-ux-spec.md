# CaptureLab 0.12.0 UI/UX 设计与交互规范

日期：2026-10-23。适用版本：`0.12.0`。基线：`0.11.2 / 534be3f`。

**文档状态：已实施的设计规范，2026-10-24 更新。** 主要界面已按本规范实现并完成本机检查；规范继续作为后续维护依据，不替代完整的实机验收。开发范围见[版本计划](0.12.0-development-plan.md)，实际结果与限制见[验收记录](0.12.0-validation.md)。

## 1. 产品原则

1. **默认值承担常规参数。** 截图、标注和保存可以直接完成；用户只在主动执行精确调整、格式转换或样式自定义时接触细节。
2. **入口围绕任务。** 菜单负责捕获和进入工具；编辑器负责当前图片；设置负责长期使用习惯。
3. **一个设置窗口。** 分类、标题、分组、设置行和反馈采用统一布局，旧入口跳转到所属分类。
4. **上下文决定可见内容。** 当前工具、选中对象和已有窗口决定哪些操作有意义，减少持续无关的灰色控件。
5. **稳定、可解释、可恢复。** 默认值不重置用户配置；处理状态可见；失败保留内容；快捷键、贴图和恢复路径始终可达。

一个新入口必须回答：对应什么用户任务、为何在这里出现、采用默认值能否完成、失败后如何继续。通用“高级设置”不作为杂项和旧参数的集中容器。

## 3. 信息架构与入口归属

| 表面 | 职责 | 主要内容 |
| --- | --- | --- |
| 菜单栏菜单 | 开始任务、访问最近结果、进入应用 | 捕获、文字与二维码、打开、最近截图、编辑器、动态窗口管理、设置／关于／退出 |
| 捕获方式选择面板 | 用一次选择开始捕获 | 区域、窗口、全屏、上次区域、延时、冻结及直接识别；显示当前快捷键 |
| 编辑器 | 处理当前文档并交付结果 | 标注、图片／对象、背景、OCR、复制、保存、上传、置顶、项目 |
| 统一设置窗口 | 修改长期偏好与服务配置 | 通用、快捷键、快捷浮层、上传；关于固定在侧栏底部 |
| 历史窗口 | 找回、继续编辑或处理历史内容 | 缩略图、打开、复制、保存、上传、置顶、删除 |

普通菜单最多两级。同一表面内一个动作保留一个主入口；顶部应用菜单按 macOS 习惯提供对应键盘入口。菜单动作复用相同的业务命令和状态判断。

## 4. 菜单栏规范

### 4.1 设计基线

以下为文字线框，实际采用原生菜单排版。图标和快捷键不是插入标题的字符；快捷键列展示用户当前有效绑定。

```text
[图标] 区域截图                 <当前快捷键>
[图标] 窗口截图                 <有绑定时显示>
[图标] 全屏截图                 <有绑定时显示>
[图标] 更多截图                 ›
[图标] 文字与二维码             ›
──────────────────────────────────────
[图标] 打开                     ›
[图标] 最近截图                 ›
[图标] 打开编辑器
──────────────────────────────────────
[图标] 浮层与贴图               ›   仅存在相关状态时
──────────────────────────────────────
[图标] 设置…                    ⌘,
[图标] 关于 CaptureLab…
       退出 CaptureLab
```

- “更多截图”：重截上次区域、冻结画面后框选、3 秒后截图、5 秒后截图、精确框选…、选择截图方式…。统一启动器的现有快捷键继续有效。
- “文字与二维码”：框选识字并复制、框选识别二维码。识别当前图片和复制已有识别结果在编辑器内完成。
- “打开”：打开图片…、打开项目…、从剪贴板打开。剪贴板动作复用现有语义：有文档时添加图层，空文档时建立图片；菜单文案应按实际行为显示“粘贴到当前图片”或“从剪贴板打开”。
- “最近截图”：最近 5 张直接点击打开，随后“查看全部历史…”。空历史只保留一条状态说明和进入历史的入口。
- “浮层与贴图”：依据实际状态显示隐藏／显示浮层、恢复最近浮层、解锁全部贴图、关闭全部贴图；无相关资源时整个子菜单及相邻多余分隔线隐藏。
- 检查更新集中于设置“关于”和 macOS 顶部应用菜单，不占常驻菜单栏行。
- 锁定贴图存在时，解锁和关闭入口不依赖编辑器是否打开；浮层恢复入口只有仍持有有效快照时出现。

默认菜单的成熟度通过分组、可读性、状态与任务路径验收，不设“为了少几行而再嵌套一层”的目标。测试典型屏幕可用高度，普通情况下菜单可完整展示；系统自身滚动行为不作为掩盖无序堆叠的办法。

### 4.2 图标、快捷键与状态

- 使用语义清楚的单色 SF Symbols。捕获组、内容组和设置组采用相同的图标槽宽及系统字号；选中／勾选标记遵循系统样式。
- 目标图标示例：区域 `viewfinder`、窗口 `macwindow`、全屏 `display`、识别 `text.viewfinder`、历史 `clock.arrow.circlepath`、设置 `gearshape`。最终以 macOS 13 支持及原生菜单实测为准，缺失图标提供可用替代。
- 文字、快捷键、子菜单箭头各用原生列；不在名称里拼空格模拟对齐，不额外注册一套全局热键来显示符号。
- 全局动作继续由现有热键控制器注册；若 SwiftUI 原生菜单不能满足展示，评估 AppKit 菜单呈现适配，保持同一动作与热键来源。
- 有效但暂时不能执行的动作禁用并有可理解的原因；与当前资源完全无关的窗口管理项隐藏。隐藏策略不能使必要恢复入口消失。
- 区域快捷键注册失败时，在相关项附近显示一条可点击的异常提示，进入设置“快捷键”并定位该行；恢复后提示消失。普通状态不显示永久的快捷键说明行。
- 菜单栏图标、菜单名称和退出操作保持系统原生风格；不在本版制作模拟原生的自定义弹出面板。

### 4.3 顶部应用菜单

顶部菜单延续“文件／编辑／截图／工具／窗口”的系统职责，调整用词和重复项。Cmd-comma 统一打开设置；“其他设置”子菜单退出常规入口。旧的设置动作仍可作为内部导航调用，目标是统一窗口的具体分类。

原生文本剪切、复制、粘贴和焦点链保持有效。全局截图热键和窗口内命令快捷键分开管理；不把已有功能的组合键改作其他用途。

## 5. 统一设置窗口

### 5.1 容器与布局

```text
┌───────────────────────────────────────────────────────┐
│ 系统窗口按钮  │ 通用                                   │
│               │                                       │
│ 通用          │ 截图完成后                            │
│ 快捷键        │ ┌ 默认操作              直接编辑 ▾ ┐ │
│ 快捷浮层      │ └ 简短必要说明                      ┘ │
│ 上传          │                                       │
│               │ 历史记录                              │
│               │ ┌ 保留数量                  30 张 ▾ ┐ │
│               │ │ 保留期限                 不限 ▾   │ │
│               │ └ 必要时显示影响数量和提交操作       ┘ │
│               │                                       │
│ 关于          │ 文字识别                              │
└───────────────────────────────────────────────────────┘
```

- 同一时刻只有一个设置窗口；菜单、快捷键或错误链接再次打开时前置并选中目标分类。普通 Cmd-comma 恢复上次分类；分类定位入口优先定位其目标。
- 初始设计尺寸为 900×640 点，最小 760×540 点；侧栏初值 200 点，可在 184～208 点范围统一调节。右侧垂直滚动，侧栏保持稳定；长标题和错误文字换行。
- 分类切换不改变窗口尺寸，不弹出另一个设置窗口。页面保持独立滚动位置；不强制每次回到第一行。
- 侧栏用一致尺寸的语义图标；选中态同时有背景和文本状态。可采用系统强调色作为点缀，图标的装饰不能干扰分类识别。
- 页面采用标题 → 分组标题 → 设置行 → 辅助说明四级层次。相关行组成轻背景卡片；设置行不做成各自独立的大卡片。
- 设置窗口最小尺寸和滚动行为需实测；设计初值可在视觉评审中统一修改并回写本文。

### 5.2 分类与字段

| 分类 | 分组及设置 | 默认／提交规则 |
| --- | --- | --- |
| 通用 | 截图后操作：直接编辑／快捷浮层／仅复制 | 新装默认直接编辑；沿用所有模式复制原图并保存历史的既定语义；即时保存偏好 |
| 通用 | 历史：保留数量、期限、恢复保护说明 | 默认 30 张、不按时间清理；草稿与实际策略分开，清理前显示影响数量，单独“应用保留设置” |
| 通用 | 文字识别：自动／常用语言组合／自选语言 | 自动使用当前系统支持的中英文和自动检测；自选列表在行内展开，显示本机支持的语言，不另开语言窗口 |
| 快捷键 | 按“截图”“文字识别”等任务分组，每个动作一行 | 显示已有绑定或“录制快捷键”；就地录制、验证和注册，成功后保存 |
| 快捷浮层 | 位置、自动关闭、跟随截图屏幕 | 默认右下角、15 秒、跟随截图屏幕；即时保存偏好 |
| 快捷浮层 | 预览大小 | 默认标准（320 点）；“外观”展开后提供紧凑／标准／较大，对应原 280／320／400，日常不展示点数 |
| 上传 | R2 服务配置、已配置状态、凭据与直链设置 | 复用现有 HTTPS 校验、Keychain 与保存事务；显式保存，不显示真实存储密钥 |
| 关于（侧栏底部） | 应用名、实际运行版本／构建号、检查更新、更新状态 | 复用现有更新服务和安装门控；显示运行包元数据，设计稿占位不写成已发布版本 |

当默认操作不是快捷浮层时，“快捷浮层”页给出一行状态及进入通用设置的链接；选项仍可编辑以准备下次使用，不强制切换截图后操作。只有依赖某个开关才有意义的子项才禁用或收起。

### 5.3 设置行组件规范

| 行类型 | 展示和操作 |
| --- | --- |
| 开关 | 左侧清楚的行为描述，右侧系统 Toggle；操作后立即生效 |
| 枚举选择 | 左侧名称，右侧当前值与选择控件；选择项使用自然语言 |
| 可展开行 | 显示当前值或简短概述，主动展开后出现自定义选项；关闭不重置数据 |
| 快捷键 | 左侧动作名称，右侧统一尺寸录入区域；状态在当前行反馈 |
| 路径／服务字段 | 字段标签、输入、必要示例及就近错误；长值不破坏对齐 |
| 有后果的提交 | 单独的说明与按钮；提交时显示影响，失败保留草稿，成功更新已应用状态 |

普通偏好不放统一的“保存／取消”页脚；快捷键注册、历史清理和 R2 凭据配置保留各自必要的提交边界。页面上要清楚区分“已生效”和“尚未保存”。

### 5.4 快捷键状态

| 状态 | 行内行为 |
| --- | --- |
| 未配置 | 显示“录制快捷键”，选中后开始监听 |
| 已配置 | 显示真实符号组合与当前注册状态；失败替换时显示仍有效的旧组合；点击替换，次级操作清除；区域截图延续当前必须有绑定的规则 |
| 正在录制 | 只该行接收组合键；说明简短；Esc 取消本次录制并恢复旧值，窗口保持打开 |
| 应用内部冲突 | 在该行说明占用动作，旧绑定继续有效，允许重新录制 |
| 系统注册失败 | 显示明确原因并保留旧注册；不显示虚假的“已保存” |
| 失去焦点／切换分类／关窗 | 停止录制，不残留事件监听，不把下一次普通键盘输入录成快捷键 |

快捷键范围仍是现有动作；参考图中的额外动作不自动扩展。使用物理键位存储，保留非美式键盘和 Shift 支持。

### 5.5 草稿与导航

- 即时偏好无需离页确认；尚未应用的历史策略在所属页保留草稿，但实际清理只由明确提交触发。
- R2 显示“未配置／已配置／有未保存更改／保存失败”等状态。修改凭据后切换分类可保留内存草稿；关闭整个设置窗口时按未保存更改提供保存、放弃、取消，保存失败保持窗口与草稿。
- 用户主动上传时如缺少有效配置，提供“设置上传…”入口并定位本窗口的上传分类；保持当前图片。只有真实上传成功才显示链接已复制，“已配置”不等同通道验证成功。
- R2 草稿不写到临时明文配置。只有当前 Access Key ID 匹配已保存 ID 时才提示“留空保留密钥”；更换 ID 后说明必须输入对应密钥。配置／草稿状态位于卡片内，保存不可用时提供说明；加载与保存失败分别显示。
- 减少因布局整合而产生的额外确认；历史删除、文档恢复和凭据变更保留现有必要的保护。

## 6. 默认参数与按任务展开

| 能力／参数 | 普通状态 | 用户主动调整的位置 |
| --- | --- | --- |
| 截图宽高、固定比例 | 自由框选；不显示宽高输入、比例选择或“应用尺寸”面板 | “更多截图 → 精确框选…”进入选区内的轻量调整状态 |
| 逻辑点与输出像素说明 | 不常驻技术说明 | 精确调整时显示必要单位与最终尺寸，避免用户误判 Retina 像素 |
| 框选操作 | 拖动并松开完成，Esc 取消 | 精确调整任务中允许调整后按 Return／明确按钮完成，简短说明仅出现于该任务 |
| 裁剪比例与精确裁剪尺寸 | 自由裁剪、拖动手柄 | 裁剪工具内的“限制比例”或“精确尺寸”展开项 |
| 输出尺寸／百分比 | 使用当前成品像素尺寸，无额外缩放 | 编辑器“调整尺寸…”；旧项目已有变换继续生效并可查看 |
| 保存格式和质量 | 常规保存为 PNG，直接选择文件位置 | 主动“导出…”切换 JPEG；质量选项仅在 JPEG 下出现 |
| 背景、留白、圆角、阴影 | 新文档沿用无附加背景／布局的现有默认值 | 背景任务先选预设并预览；自定义时展开对应细节 |
| 字体、字号、边框等文字参数 | 新标注使用默认样式，选中文字时显示必要属性 | 文字工具或选中文字的属性区，样式细节按需展开 |
| 颜色、线宽、滤镜强度 | 只显示当前工具支持的属性 | 当前工具／选中标注的属性区，不支持的属性退出当前布局 |
| 浮层宽度点数 | 标准大小，由应用处理 | 设置“快捷浮层 → 外观”，使用紧凑／标准／较大名称 |

“精确框选”复用现有选区几何和约束能力，使用同一选择层，不再增加一个必须先填表的独立页面。该任务松开鼠标后保留选区供调整，Return／确认完成，Esc 取消整个任务；普通框选始终保留松开完成的既定行为。进入任务的差异须在状态提示中明确。

关闭展开区只改变展示，不清空值。已有项目或用户明确保存的非默认值，在所属任务中显示真实值并提供恢复默认；不得通过隐藏控件默默改写输出。普通框选的初始自由比例是本次任务的默认，不修改“重截上次区域”的持久化记录。

## 7. 编辑器与结果交付

### 7.1 编辑器布局

- 画布是视觉中心。常规选择／对象／预览状态仅保留 52 点主工具栏及分隔线；标注工具、选中标注或裁剪时，按上下文增加 40 点属性行。顶部预留与可见行同步，不留下常驻空白参数区。
- 主工具栏按捕获／打开、编辑工具、视图／图层／背景及结果动作组织。缩放留在主栏；900 点等紧凑窗口将撤销、重做、OCR 和单独复制收进“图片操作”菜单，键盘入口继续有效，保存和复制并关闭保持可见。宽窗口可直接展示这些快捷按钮。
- 原生三个窗口按钮的水平安全区保留，不把 88 点误当垂直空白或直接缩到 44 点。标注样式集中在“更多工具 → 标注样式…”，不单独挤占属性行。
- 常驻工具的设计基线为选择、箭头、矩形、文字、马赛克；裁剪、其他形状、曲线箭头、画笔、高亮、计数器、聚光灯和模糊在有名称的“更多工具”中可达。最终常驻组合在视觉评审中核对，全部现有工具保留。
- 选中工具有持续明确状态；图标有工具提示和辅助功能名称，更多工具内显示图标与名称。已有键盘操作仍有效。
- 属性区随工具或选中对象变化：图形显示颜色／线宽，文字显示颜色／字号等，图片对象显示必要变换；不常驻无关字号、线宽与禁用字段。
- 图层列表与对象属性采用可收起的侧面板，宽度 280 点，默认关闭。主栏图层按钮承担展开／收起，提示和选中态同步；侧栏不保留只有关闭图标的空白行。选择工具与对象操作有统一反馈；工具切换自动进入对应编辑状态。
- 侧栏中的图片精确变换默认收起；选中标注可通过“编辑标注”回到对应属性。添加图片等明确的对象操作可主动打开侧栏，替换文档或切换标注工具时同步编辑状态。
- 底部退出常驻“标注／图层／预览”三模式选择。图层由明确的图层按钮进入；最终预览由“预览成品”动作进入，退出可回到先前编辑状态；背景与导出有各自预览。
- 底部仅显示文档名称、尺寸及正在进行的上传／识别；操作成功由带身份的反馈事件统一呈现短暂提示，重复同一操作也能再次出现。失败继续使用需主动关闭的错误对话框，保存／关闭失败保留文档，不设置自动消失期限；“项目”操作集中到文件菜单与明确的项目入口，避免在状态栏堆叠多组控制。
- 最小编辑器尺寸设计目标为 900×600 点，默认 1080×680 点；开启侧面板后优先调整画布和工具布局，不挤出结果按钮。须实际验证可行性，若需调整最小尺寸应记录依据并更新验收尺寸。

### 7.1.1 捕获与识别辅助窗口

- 捕获选择面板说明为“选择一种截图方式”，不把自由框选提示用于全部九个动作。
- 识别窗口明确区分未开始、进行中、无结果、失败和有结果。进行中居中显示进度及说明，复制不可用的原因可读；失败显示错误详情。
- 未开始、无结果和失败均提供框选入口；再次框选默认沿用上次识别种类，也可切换文字／二维码。该动作重新捕获，不为重试常驻保留完整截图；关闭仍取消请求，过期请求不能覆盖新结果或剪贴板。

### 7.2 常规结果动作

| 动作 | 预期结果 |
| --- | --- |
| 复制 | 复制当前精确合成图，保留编辑器，显示短暂成功反馈 |
| 保存图片… | 直接打开系统保存面板，保存当前成品的原尺寸 PNG；不经过参数表单 |
| 复制并关闭 | 沿用现有完成动作：先持久化当前项目和预览，再复制成品；全部成功后关闭。失败保持文档、撤销状态和窗口 |
| 导出… | 用户主动转换格式或查看文件大小；显示格式、成品预览和大小；尺寸沿用成品，调整尺寸是显式展开的任务 |
| 上传到 R2 | 沿用精确 PNG 上传及复制直链；显示上传中、成功或失败状态 |
| 置顶 | 使用当前成品快照，贴图操作入口与编辑器关闭相互独立 |
| 保存可编辑项目… | 单独的明确名称，保持与分享 PNG／JPEG 的区别 |

工具条常驻结果入口为保存图片…、复制并关闭；宽窗口另显示复制按钮，紧凑窗口可在图片操作或键盘命令中复制。上传、置顶和导出在清楚命名的次级操作中可达，不与主要动作全部等权展示；快捷浮层和历史的现有快捷操作保持。

普通保存与主动导出的设置分开：PNG 保存不套用上次 JPEG 格式或其他文档的目标尺寸。主动导出可记忆格式与质量，尺寸默认匹配当前成品；兼容读取旧配置，避免旧尺寸悄悄应用到新文档。

### 7.3 背景、样式与预览

- 背景任务先展示“原图”、内置样式和个人预设缩略项以及预览；打开时加载真实文档状态，不默认添加边框、阴影或改变比例。
- 选预设后可在同一任务中展开“自定义”，分组显示背景、布局和阴影细节；选某种背景后只出现该类型需要的控制。
- 比例、圆角、留白和阴影参数不进入日常截图和标注路径。个人预设管理与所选样式就近组织。
- 背景／布局编辑使用可取消草稿，应用后作为一个可撤销编辑；切换文档后的旧草稿不能写入新文档。
- 预览中的等待、失败与过期结果明确处理；遮挡、图层、变换及背景继续共享同一精确输出语义。

## 8. 视觉组件规范

以下为设计初值，用于实现时建立统一常量或组件；系统原生菜单、控件和辅助功能设置优先。调整初值须全局一致并回写文档。

| 项目 | 规范 |
| --- | --- |
| 字体 | 系统字体；设置页标题 22 点 semibold，分组标题 13 点 semibold，主要设置行 13 点 regular，辅助说明 11～12 点 secondary |
| 间距 | 以 4／8 点为基础；内容外边距 24～28，分组间距 24，组内水平边距 16；正文与辅助说明间距 4～6 |
| 设置行 | 单行初值最小高 44 点，标签／控件垂直居中；多行内容自然增高，不固定高度裁切 |
| 卡片 | 圆角初值 10 点，语义化轻背景；相关行之间用低对比细分隔线，避免厚边框和重复阴影 |
| 控件 | 系统 Toggle、Picker、文本输入和按钮；同类行的控件位置与宽度一致，不为每页另造样式 |
| 颜色 | 使用语义化窗口、内容、分组、文本和强调色；成功／失败另有文字或图标，不只靠颜色 |
| 图标 | 相同层级采用相同尺寸和笔重；设置侧栏图标槽初值 24～28 点；菜单图标使用原生菜单尺寸 |
| 按钮 | 一个任务有清楚的主动作；默认／悬停／按下／禁用／键盘焦点完整；内容区常用目标至少 28 点高 |
| 长文与错误 | 支持换行；主标签、值和按钮优先可见；通过垂直滚动容纳内容，不用省略号隐藏关键失败原因 |
| 深浅色与对比 | 采用系统语义颜色；检查深色、增强对比度、减少透明度及系统强调色，避免固定白底／黑字 |

本版不引入以装饰为目的的复杂动效、页面阴影堆叠或拟网页仪表盘布局。动效用于状态切换和短暂反馈，并尊重减少动态效果设置。

### 9.2 状态反馈

| 状态 | 表现与恢复 |
| --- | --- |
| 短操作成功 | 内容区统一位置显示短暂提示，例如“图片已复制”；设计时长约 1.5～2 秒，不夺取键盘焦点 |
| 上传／识别／编码中 | 在动作或结果区显示进行中状态，相关动作避免重复触发；无可测百分比时用不定进度，不伪造进度 |
| 可恢复错误 | 就近显示原因和下一步，例如重新录制、重试保存或进入上传设置；错误内容保留到解决或用户关闭 |
| 历史忙 | 保留列表和当前文档，显示稍后刷新／重试；不误报索引损坏，不自动清理 |
| 保存／退出失败 | 明确说明未关闭，提供继续编辑或重试；不靠一闪而过的提示承载失败 |
| 需要确认的数据删除 | 说明作用对象及数量，保留现有历史并发确认；安全取消为默认路径 |
| 无内容 | 编辑器给截图／打开图片入口；历史说明尚无截图并提供开始任务的路径；无浮层／贴图的管理项隐藏 |

首次截图的屏幕录制权限失败提供易懂的系统设置路径和可执行的设置入口；不增加一套冗长的新手向导。无法直接定位时保留文字指引。授权失败、取消和重试都不能破坏当前文档。

## 10. 关键交互状态矩阵

| 场景 | 菜单／页面预期 | 必须保留的内容 |

| 历史锁忙／磁盘失败 | 提示可恢复原因，保持窗口 | 文档、历史列表、撤销及恢复资源 |

## 11. 可访问性与视觉验收

- 菜单可用键盘导航；设置侧栏、设置行和按钮有连续合理的 Tab 顺序，焦点可见。快捷键录入中的 Esc 优先取消录制，避免连带关窗。
- 图标操作提供辅助功能名称；VoiceOver 能读出分类选中、开关值、快捷键录制状态、控件禁用原因和关键错误。状态变化的公告不重复打断输入。
- 中英文分别检查菜单、设置行、按钮、说明和错误，不用为中文凑出的空格或固定宽度对齐英文。
- 设置在 760×540 和 900×640 点检查；编辑器按第 7 节的最小和默认尺寸检查，并检查大字号／长错误时的布局。
- 检查浅色、深色、增强对比度、减少透明度和减少动态效果；截图、浮层、贴图在多屏／Space 下的实际结果独立记录。
- 每次视觉评审至少覆盖菜单普通／异常状态、设置各分类、快捷键冲突、R2 草稿及错误、普通／精确框选、编辑器空态／选中对象、背景、普通保存和主动导出。
- 使用合成图片、文字和二维码及临时配置生成证据；参考图标明第三方来源，成品图标明实际 CaptureLab 版本。不要将设计稿或历史截图当成本版实测。
