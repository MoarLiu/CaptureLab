# CaptureLab 0.11.1 发布验收记录

日期：2026-10-11。基线：0.11.0 / `6bc9b61`。目标：0.11.1，构建 17，标签 `v0.11.1`。准备分支：`main`。

## 修复范围

- 历史索引损坏或丢失时恢复全部记录，独立读取仍可用的保留策略。恢复保护随索引持久化，刷新、重启、期限到期及另一当前版本实例写入都不会自动删除恢复记录；重新应用保留设置仍预览删除数量并走现有确认。
- 添加图片、复制图片图层和应用自定义背景前，通过实际项目编码器检查完整资源与编码开销。超限时保留原文档、选区和撤销记录；原生画布及图层列表只在提交成功后切换选区。普通位置、旋转及排序调整复用现有资源，不额外执行项目编码。
- 序号标注递增采用可检测溢出的运算；项目包含最大整数标签时，继续添加编号会选择未使用的正整数。

新增六项回归覆盖索引中的单个损坏字段、保留 300 张的索引完全损坏或丢失、恢复写入前后失败、跨重启和旧实例写入、原生复制提交拒绝、实际大图片组合及背景容量，以及最大整数序号项目重开后的继续编号。

## 兼容性

可编辑项目继续使用格式 2，已有格式 1／2 项目仍可读取。历史索引增加可选的恢复保护字段；旧版本可以读取记录但不识别保护，可能按旧保留规则清理。请避免在重新审阅保留设置前用旧版本打开恢复后的历史。

## 验证

全新 `.build/release-0111-final` 构建目录，完整 Xcode，启用 `-strict-concurrency=complete -warnings-as-errors`：380 项通过，0 失败、0 跳过。ARM64 与 x86_64、最低 macOS 13 的 Release 严格编译均通过。

测试、严格编译、打包、签名、隐私、挂载与启动报告保存在忽略的 `dist/validation-0.11.1/` 中。源码隐私匹配均为合成测试、公开签名信息或实现字段，没有真实凭据、用户历史或个人路径。

两份 DMG 均通过只读挂载、文件清单、版本 0.11.1／构建 17／macOS 13、主程序与辅助程序架构及固定签名身份核验、SHA-256 和 Ed25519 更新签名验证。挂载、打包及安装验证副本逐文件相同，启动后副本内容仍与校验清单一致。

包内仅有 Info.plist、主程序、更新辅助程序、图标和签名资源；卷根目录另有 Applications 链接。没有私钥、用户历史、配置、样例图片、项目、日志、AppleDouble 或个人构建路径。打包前后源码、测试及图标的哈希未变。

ARM64 原生及 x86_64 经 Rosetta 的隔离安装副本，均验证实际可执行文件路径。两种启动方法使用隔离的历史目录，未替换正式安装的应用：
