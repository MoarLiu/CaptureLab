## 复审发现与修复

复审确认一项发布阻断：安装脚本设置 `LC_ALL=C` 后，macOS `ps` 将中文等非 ASCII 路径转义，导致已成功启动的更新进程无法匹配，触发错误回滚。上轮将它归为 LaunchServices 环境时序限制的结论已撤回。

所有读取进程命令行的调用改为局部 `LC_ALL=en_US.UTF-8`，版本排序和进程启动时间标识保持原规则。真实进程回归在修复前匹配失败、修复后匹配成功，覆盖进程记录、重启检查与进程身份跟踪。隔离目录中，修复后的安装服务将真实 0.10.1 副本正常退出、替换为最终 0.11.0 包、重启并清理三件套下载资产；正式安装位置未被替换。退出前编辑恢复、写入失败、取消退出和交换回滚继续由自动化验证，未宣称完整 UI 点击更新并编辑恢复的端到端实测通过。

旧版本中已嵌入的安装器不会因新 DMG 自动改变。0.10.1 若位于中文路径而更新回滚，需要手动安装本版或先移至 `/Applications`；本版修复适用于其后发起的更新。

菜单复审：旧中文 JSON 的顶部菜单快照未刷新，不作为动态启用状态证据。重新刷新原生菜单后，中英文空文档／有图／截图中／识别中的顶部菜单状态全部通过。状态菜单仍为 13 个一级入口。截图和更新期间禁用相关动作，上传和 OCR 按钮分别防止重复执行；普通编辑不会仅因后台上传而被全面禁用。
