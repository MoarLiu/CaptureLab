# CaptureLab 0.5.1 后续开发计划

制定日期：2026-10-02。代码基线：`v0.5.1` / `7c4fd1c`。

状态：0.8.0 已完成实现、代码审查修复、自动化验证及发布准备并获发布确认；完成范围及待人工验收项见 [0.8.0 开发记录](0.8.0-development-plan.md)。0.9.0 及后续版本仍为规划，下列版本号不代表发布日期。

## 目标和范围

补齐此前与 CleanShot X 对比中列出的 12 类截图功能差距，继续定位为原生 macOS 截图、编辑、参考和分享工具。

已具备的基础能力继续沿用：区域／全屏／窗口／延时截图、标注颜色／线宽／字号、裁剪、撤销／重做、置顶贴图及尺寸／透明度控制、完整历史缩略图库、本地 OCR、PNG 输出、R2 上传。

本计划明确排除：

1. 录屏与 GIF，以及系统声音、麦克风、摄像头、录制按键和点击显示。
2. 视频编辑，包括智能缩放、光标平滑、视频背景和多比例视频导出。
3. 云端分享管理，包括分享页面、密码、有效期、远程撤销链接、云端图库和评论。已有 R2 上传和复制直链继续维护；快捷浮层中的上传复用该能力。

规模是相对复杂度判断，不是工期承诺。每个里程碑先完成交互和数据模型设计，再实现、验证；确切工期在该阶段设计完成后估算。

## 0.6.0：截图后的快捷工作流

### 功能

- 截图后显示角落缩略浮层，提供复制、保存、编辑、置顶、R2 上传、关闭和拖出入口。
- 设置截图后的默认行为：快捷浮层、直接编辑、仅复制；升级时保留既有行为，用户可切换。
- 浮层支持位置、尺寸、自动关闭时间、多屏归属、暂时隐藏和恢复最近关闭项；连续截图可访问多个结果。
- 支持从剪贴板粘贴图片、从 Finder 等应用拖入图片，以及从编辑器／浮层／历史将合成图片拖到其他应用。
- 本阶段导入图片作为独立文档；向现有画布添加图片在 0.9.0 交付。替换已有编辑内容时保留结果或提供保存入口，避免直接丢弃修改。
- 置顶贴图增加锁定／鼠标穿透、方向键微调、Shift 加速移动；菜单栏提供始终可达的解锁和关闭入口。
- 历史支持数量和期限设置。默认延续 30 张；建议数量选项为 30／100／300，期限为不按时间清理／1／7／30 天，同时开启时按先达到的限制清理。降低保留上限前显示受影响数量。

### 实现边界

- 将截图完成后的持久化、复制和展示行为分开，避免现有“截图成功即打开编辑器”逻辑继续扩散。
- 建立共享的图片导入、渲染快照和文件拖出通道，供后续多图与格式导出复用。
- 浮层与具体截图绑定，复制／保存／上传使用该截图的稳定快照，不读取可能已切换的当前编辑文档。
- 浮层、贴图和编辑器一并在截图期间隐藏；历史保留设置和清理复用现有进程间锁。

### 验收

- 连续截图、切换文档或关闭编辑器，不会让浮层复制／上传错误的图片。
- 在 Finder、浏览器上传区域及可接收图片的原生应用完成粘贴和拖放验证；接收方写入完成前临时文件有效。
- 文本框中的粘贴仍按文本处理；图片导入失败时保留当前文档。
- 穿透后能操作下层应用，也能随时解除锁定；多屏和全屏 Space 下行为明确。
- 修改保留策略、同时运行两个实例或磁盘写入失败时，历史图像与索引保持一致。

## 0.7.0：精确截图与直接识别

### 功能

- 保存最近一次成功的区域选择，并提供“重截上次区域”。
- 区域选择支持输入宽高、比例预设、锁定比例、键盘微调、十字参考线和放大镜；明确显示逻辑尺寸与实际输出像素。
- 提供冻结画面后选择区域的模式，便于捕获变化中的界面。
- 增加统一截图入口，集中选择区域／全屏／窗口／延时等已有模式。
- 全局快捷键按动作配置，覆盖区域、全屏、窗口、延时、上次区域、统一入口、文字识别和二维码识别；显示冲突和注册失败原因。
- 增加“框选识字并复制”，无需进入编辑器；识别失败或无文字时保留剪贴板原内容。
- 二维码支持多个识别结果的选择与复制。
- 语言设置从当前 macOS 的 Vision 支持列表生成，可选择常用语言组合；不预先承诺所有系统都支持相同的语言数量。

### 实现边界

- 精确选择需要自有区域选择层，不能只向现有系统 `screencapture` 命令增加菜单项。
- 区域坐标记录显示器身份与逻辑坐标，并在捕获时转换为像素；显示器移除或分辨率改变后校验旧区域。
- OCR 与二维码复用捕获结果和取消机制；迟到的识别结果不得覆盖更新的任务结果。

### 验收

- Retina、不同缩放比例、多屏负坐标、跨屏选择、屏幕配置变化都有明确测试案例。
- 无效的上次区域提示重新选择，不静默截取其他位置；取消截图不覆盖最近成功区域。
- 尺寸和比例设置与输出像素一致；冻结模式不会混入自身浮层。
- 多快捷键注册失败可回退，不导致原有快捷键全部失效；覆盖非美式键盘和带 Shift 的组合。
- 中英文混排、低对比文字、空白区域、多二维码、用户取消及任务替换均验证。

## 0.8.0：可编辑文档与图片调整

### 功能

- 定义带版本号的本地 `.capturelab` 项目格式，保存源图片、标注、画布与变换信息。
- 支持显式保存／打开项目；新历史记录保留可编辑状态，完成编辑后再次打开仍可修改原来的文字、箭头等对象。
- 已有 PNG 历史保持可用，但无法从合成像素恢复旧标注；以单张底图导入。
- 增加按宽高或百分比调整输出尺寸、保持比例、90 度旋转、水平／垂直翻转。
- 裁剪增加比例预设、精确尺寸、选区移动／调整和边缘吸附。
- 文档关闭或被新截图替换前保存可恢复状态；磁盘写入失败时保留编辑内容并提示重试。

### 实现边界

- 先统一文档坐标、图片资源引用、对象变换和撤销模型，再实现旋转、尺寸变化及项目保存。
- 项目保存当前可编辑状态，不要求将整个撤销栈持久化；重新打开后的新编辑仍支持撤销／重做。
- 撤销快照引用共享图像资源，避免每个操作复制完整大图；为后续多图组合预留资源和层级结构。
- 历史从单 PNG 扩展为预览图与可编辑文档的关联记录，保留旧索引读取和迁移能力；新旧文件统一参与保留清理。
- 预览、复制、保存、置顶与 R2 上传使用一致的合成结果。可编辑项目可能包含原图，保存入口明确区分项目与分享图片；普通分享动作只输出合成图。

### 验收

- 保存、退出、重启和重新打开后，对象位置、文字、样式、裁剪和变换一致。
- 旋转／翻转／裁剪／缩放组合后，预览和输出一致，标注命中与撤销正确。
- 马赛克及其他遮挡在普通图片输出中始终保留；渲染失败不得回退输出未遮挡的源图。
- 项目写入中断、损坏、缺失资源、未知版本、并发历史操作不会破坏原有文件。
- 旧历史仍可打开；新历史“完成—关闭—重开”保留标注可编辑性。

## 0.9.0：进阶标注和多图组合

### 功能

- 增加椭圆、实心矩形、曲线箭头、聚光灯和可调强度的模糊工具；保留现有马赛克。
- 箭头提供样式选择和曲线控制点；形状支持描边／填充样式。
- 文字支持字体与字重、对齐、背景／边框和可复用样式；增加常用颜色收藏。
- 画笔增加平滑处理；高亮增加依据文字区域辅助对齐的能力，并保留手动调节。
- 向现有画布粘贴或拖入多张图片，支持移动、缩放、旋转、层级调整、对齐和间距辅助。
- 多对象选择、组合移动、复制／删除，以及横向／纵向排列快捷操作。
- 多图和所有新增标注都支持项目保存、历史恢复、撤销／重做。

### 实现边界

- 使用 0.8.0 的文档和层级模型；避免每加入一张图片就把所有内容永久合成为底图。
- 更新文档格式版本，并明确不兼容旧客户端时的提示。
- 模糊用于视觉处理，不替代马赛克遮挡；跨图层的遮挡和变换纳入共同渲染流程。

### 验收

- 新工具在不同预览倍率与导出尺寸下保持外观一致；可选择、调整、删除和撤销。
- 多图叠放与重排后，遮挡、选中顺序、旋转缩放中心正确；保存重开不改变层级。
- 大图与多图压力场景有资源预算和可理解的失败提示；新图片加载失败不损坏现有画布。
- 所有新增工具提供可见入口、中文／英文文案、键盘操作和基本辅助功能标签。

## 0.10.0：背景、模板与多格式导出

### 功能

- 图片背景支持纯色、渐变、内置背景和自定义图片。
- 支持留白、圆角、阴影、对齐、输出比例，以及依据内容范围自动平衡留白。
- 预设包含 1:1、4:3、16:9、9:16 和自定义比例；可保存、应用和删除个人样式预设。
- 保留 PNG，并增加 JPEG 导出、质量调节、尺寸设置与预计文件大小预览。
- 导出流程可复用最近配置；透明内容转 JPEG 时明确使用的背景色。
- 背景与布局保存到项目中；R2 上传继续沿用现有 PNG 合成图通道，体现当前背景和布局。

### 验收

- 背景、留白、阴影和圆角在编辑预览、复制、拖出、保存、置顶与 R2 输出中一致。
- PNG 透明通道、JPEG 背景合成、色彩、尺寸和质量选项按设置输出。
- 模板更换可撤销，已有标注和图片位置按既定布局规则处理；预设跨重启可用。
- 文件大小估算不阻塞界面；快速变更设置不会显示旧任务的估算结果。
- 自定义背景失效时提示修复，不静默输出错误背景。

## 0.11.0：滚动长截图

### 提前验证

在 0.6.0 阶段建立独立原型：手动滚动选定区域，按需取得静态图像，验证重叠识别和拼接。不提供录像或 GIF 输出。

验证样本包含浏览器长页面、原生滚动列表、聊天记录、代码编辑器；覆盖固定顶部栏、动态内容、重复纹理和缩放后的文字。记录成功条件、失败条件、误拼接情况和内存开销，避免以单一网页成功推定所有应用兼容。

### 分步交付

1. **纵向手动滚动**：框选滚动区域、用户滚动、连续拼接、实时缩略预览、结束和取消。
2. **纠错与稳定性**：固定区域处理、重复帧识别、误拼接提示、丢弃最后一段、手动调整接缝和最大尺寸／内存预算。
3. **横向滚动**：复用拼接管线，增加方向选择与横向预览；在每次会话中固定一个滚动方向。

三步都完成后才视为本阶段结束。自动滚动属于可行性验证后再评估的增强项，不作为手动滚动长截图的前置条件；不承诺任意应用或任意动态页面都可自动拼接。

### 实现边界

- 优先采用用户主动滚动的方案；若后续自动滚动需要额外系统权限，单独评估其收益和交互。
- 拼接任务与编辑文档、OCR、上传隔离，支持取消、超时和中断清理。
- 长图进入现有编辑、历史、项目和导出流程，预览采用缩略图／分块策略，避免全尺寸重复分配。
- 检测到低置信度接缝时允许纠正或停止，避免静默输出缺行、重行的结果。

### 验收

- 使用已知完整内容的合成页面验证漏行、重行、接缝、文字清晰度和最终尺寸。
- 对实际应用建立兼容清单，区分通过、有限支持和不支持；注明测试的 macOS 与应用版本。
- 滚动过快、反向滚动、窗口移动、屏幕变化、内容刷新、权限拒绝和取消都有确定行为。
- 验证长图编辑、导出、R2 上传、历史恢复及资源限制；失败不影响下一次普通截图。

## 依赖关系与模块落点

- **0.6.0 → 0.7.0**：共享设置、快捷动作和截图结果分发，供精确捕获及直接 OCR 使用。
- **0.8.0 → 0.9.0 → 0.10.0**：文档／资源／变换先稳定，再增加图层和新工具，最后增加背景布局与导出配置。
- **滚动验证 → 0.11.0**：先明确兼容范围，正式交付复用前面完成的编辑、历史和导出能力。

现有主要落点：

| 模块 | 计划职责 |
| --- | --- |
| `CaptureLabViewModel`、应用入口与命令菜单 | 拆出捕获结果分发与共享动作，避免全部新增逻辑继续集中到视图模型 |
| `ScreenCaptureService`、`CaptureMode`、快捷键控制与存储 | 精确选择、模式入口、多动作快捷键、滚动会话 |

| `TextRecognitionService` | 语言能力查询、直接 OCR 与二维码 |
| 新增导入／导出和背景布局模块 | 图片拖放、文件交付、格式编码、预设与布局 |

## 统一完成标准

- 每个版本有范围说明、用户可达入口、默认行为和明确的错误／取消流程。
- 针对新增状态变化、几何转换、文件持久化、渲染一致性和失败恢复编写必要回归测试，并运行现有完整测试。
- 使用完整 Xcode 验证严格并发编译及 arm64／x86_64 构建；macOS 13、Intel、多屏、混合缩放和全屏 Space 的实机情况逐项记录，未验证项不写成通过。
- UI 使用合成图片、文字与二维码做视觉检查；复杂交互还需实际拖放、窗口和快捷键验证。
- 保持截图取消、遮挡输出、OCR／上传迟到结果隔离、历史并发写入、签名更新等现有回归能力。
- 为新增设置和文档格式提供升级迁移与失败恢复路径；旧数据兼容范围明确。
- 一个阶段的验收完成后再决定进入后续阶段。版本发布另走发布流程，本计划不包含提交、打 tag、推送或上传发布资产。
