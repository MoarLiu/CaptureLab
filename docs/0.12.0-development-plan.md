## 1. 版本目标

将 CaptureLab 整理为有统一界面与操作秩序的原生 macOS 菜单栏截图工具。用户能够直接截图、标注、复制或保存；应用负责常规尺寸、比例和编码参数。用户进入设置时，获得一个结构稳定、布局统一的设置窗口。

本版解决三个已明确的问题：

1. 截图及编辑过程中常驻宽高、比例等参数，增加不必要的选择。
2. 菜单按能力堆叠，捕获、编辑、窗口管理和设置的归属不清晰；早前 33 → 13 项的调整仅解决了部分长度问题。
3. 设置分散于独立窗口，控件、间距、说明及保存反馈缺少统一规范。

衡量依据是完成任务所需的注意力、路径是否清楚，以及界面是否一致。菜单行数与设置项数量仅作为布局观察数据，不作为单独的完成指标。

## 2. 已确定的需求与参考边界

| 来源 | 纳入本版的要求 |
| --- | --- |
| 用户对参数页面的反馈 | 常规截图由默认值完成；宽高比、精确尺寸、质量等不进入普通截图和保存的必经路径 |
| 用户对菜单栏的反馈 | 按任务分组，统一图标、快捷键列、状态及用词，消除能力堆叠和长期无关的灰色项目 |
| Shottr 菜单参考 | 菜单承担快捷操作与应用入口；分组清楚，设置入口集中 |
| CleanShot 菜单参考 | 图标、名称、快捷键按一致规则排列；捕获、文档操作、历史及应用管理有清楚归属 |
| CleanShot 设置参考 | 统一设置窗口、侧栏分类、分组卡片、设置行和明确的控件语义 |
| 用户对 R2 的补充 | 上传通道已有用户手动验证；保留这份证据，不再笼统标为“R2 未验证” |

参考截图已保存于 [docs/assets/0.12.0/](assets/0.12.0/)，对应关系及采用原则见设计规范。截图中的录屏、账号体系、云分享管理和桌面壁纸能力不扩展为本版需求。滚动截图继续沿用已取消的产品决定。

用户已确定的是上述目标和体验方向。本文及配套规范中的具体菜单顺序、尺寸初值、分类名称据此形成，并已进行本机原生渲染和差异复审；用户体验评审与尚未覆盖的环境项目保持独立记录。

## 3. 当前实现核对

| 表面 | 0.11.2 当前实现 | 0.12.0 调整方向 |
| --- | --- | --- |
| 菜单栏 | 13 个普通一级入口；包含“当前图片”“打开与粘贴”等子菜单，区域快捷键通过标题拼接显示 | 按任务统一菜单结构及图标／快捷键列，编辑动作回到编辑器，必要窗口管理按状态出现 |
| 设置 | 截图与历史、快捷键、识别语言、R2 各有窗口 | 统一设置容器；旧入口定位到对应分类，不再打开并列设置窗口 |
| 区域选择 | 每次创建 174 点高的参数面板，包含宽高、比例、应用尺寸等 | 普通框选默认直接完成；精确调整改为用户主动进入的选区操作 |
| 截图启动器 | 逐行动作列表，含尺寸／比例及回车操作说明 | 做成紧凑的捕获方式选择面板，文案与“松开鼠标截图”的实际默认行为一致 |
| 编辑器 | 两排工具条、底部“标注／图层／预览”切换；部分属性常驻 | 常用工具优先，属性随当前工具／对象出现；收敛模式入口和参数面板 |
| 保存／导出 | “保存为”打开包含尺寸等参数的导出表单；另有直接 PNG 保存 | 常规“保存图片…”直接打开系统保存面板；格式转换与尺寸调整各有明确任务入口 |
| 背景／样式 | 背景、圆角、阴影、比例及个人预设以长表单展示 | 预设与预览优先，细节在当前任务中按需展开 |
| 结果反馈 | 工具条复制／上传有提示，其他操作主要通过底部状态或弹窗反馈 | 统一成功、进行中、失败及可恢复状态的展示 |

此表为源代码与既有界面记录核对，不等同对所有系统版本和真实交互的重新验收。

### 4.2 沿用的能力与行为约束

- 保留现有捕获模式、OCR／二维码、编辑工具、独立图层、可编辑项目、背景预设、历史、贴图、浮层及 R2 能力；入口和展示时机可以调整。
- 新安装的截图后默认行为暂沿用“复制原图并打开编辑器”；升级保留用户选择的直接编辑、浮层或仅复制模式。
- 普通截图默认自由框选，按现有显示器像素密度输出；常规保存为当前成品的 PNG，不额外改变尺寸或比例。
- 保留项目格式 1／2 读取和格式 2 写入；保持历史恢复、关闭前保存、失败保留文档及并发版本保护。
- 保留已配置的全局快捷键、R2 凭据与路径设置、识别语言、历史保留策略及个人预设。
- 贴图穿透后，“解锁全部贴图”和“关闭全部贴图”必须在菜单栏可达；浮层恢复入口按可恢复状态出现。
- 已有项目中的裁剪、输出尺寸和背景布局照常呈现；隐藏默认参数不能改变旧文件的输出。

### 4.3 本版不扩展的范围

录屏／GIF、视频编辑、滚动截图、账号体系、云端图库／分享管理、壁纸功能，以及开发者签名／公证迁移均不属于本版开发任务。新的开机启动、隐藏菜单栏图标和设置搜索能力也不因参考图而自动加入；本版先把已有能力组织完整。

文档阶段的只读范围已由后续实现授权更新。本地实现及版本元数据已完成；打包发布、提交、标签和推送不包含在本轮操作中。

## 7. 数据、状态与迁移

1. 设置窗口是单实例；再次打开时前置已有窗口并定位分类。Cmd-comma 进入该窗口，不产生第二套设置。
2. 普通偏好即时生效；历史清理、快捷键注册、R2 凭据保存各自保留必要的提交和失败恢复，具体规则见规范。
3. 旧配置键和 Keychain 身份优先沿用。退出常规界面的参数仍保留其数据，用户主动调整时显示真实值并可恢复默认；不能静默覆盖非默认设置。
4. 新建截图采用自由框选。先前一次精确框选的约束不污染下一次普通截图；“重截上次区域”继续使用已记录的成功选区。
5. 合成、OCR、导出和上传继续复用精确输出；交互预览的近似图不进入最终结果。马赛克与不透明遮挡的现有回归继续保留。
6. 锁忙、磁盘写入失败、导入失败和退出取消必须保留原文档；切换分类或关闭辅助面板不得绕过保存门槛。
7. 截图、识别、上传及更新期间使用各自状态门控；菜单与编辑器对同一动作的启用规则保持一致。

### 回归重点与已有证据
