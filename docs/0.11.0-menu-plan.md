### 顶部应用菜单栏

以下统计应用自行添加的入口，不包含 macOS 自动提供的关闭窗口、文本编辑、服务、隐藏、窗口排列等项目。系统项目的可见情况取决于焦点窗口和系统版本。

| 菜单 | 调整前自定义项目 | 数量 |
| --- | --- | --- |
| CaptureLab | 截图设置、检查更新、Cloudflare R2 设置 | 3 |
| 文件 | 打开项目、区域截图、全屏截图、窗口截图、延迟截图、粘贴图片、打开图片、显示 CaptureLab、截图历史；导出 PNG/JPEG、保存可编辑项目、保存编辑后图片、复制编辑后图片、上传编辑后图片、贴图置顶 | 15 |
| 编辑 | 撤销、重做、清空标注；其余为系统文本编辑命令 | 3 |
| 截图 | 统一入口、重截上次区域、冻结框选、框选识字、框选二维码、识别语言；区域、全屏、窗口、延迟；打开图片、复制图片、保存图片、上传图片 | 14 |
| 工具 | 添加图片到画布、选择多个对象；15 种工具；运行 OCR、复制 OCR 文本、清空 OCR 文本 | 20 |
| 显示／窗口／帮助 | 由 SwiftUI／AppKit 提供，窗口菜单还包含各功能窗口入口 | 不作静态总数承诺 |

15 种工具为：选择、裁剪、箭头、直线、矩形、椭圆、实心矩形、曲线箭头、聚光灯、模糊、计数器、画笔、文字、文字高亮、马赛克。

### 编辑器内菜单

编辑器已经提供工具条、OCR、复制、上传、保存为、完成，以及高级样式、图层、背景、图片调整、撤销／重做、置顶、历史入口。底部还提供项目打开／保存、粘贴和拖出。

图片调整子菜单为添加图片、输出尺寸、旋转、水平翻转和垂直翻转；项目子菜单为打开项目和保存可编辑项目；缩放菜单为适应、50%、100%、200%。编辑器中的直接操作适合保留，状态菜单不需要再逐一铺开相同工具。

## 调整前主要问题

1. 状态菜单混合了开始截图、编辑当前图、窗口管理、偏好和应用管理，且区域截图排在较靠后的位置。
2. “文件”和“截图”重复提供捕获、打开、复制、保存、上传；入口归属不明确。
3. “工具”将标注类型与 OCR 混在一起，15 种工具缺少分组。
4. 截图设置、快捷键配置、识别语言和 R2 设置散落在多个位置。
5. 最近截图需要进入“最近截图 → 某张图片 → 动作”，打开最近图片也要多走一层。
6. “保存为”“保存编辑后图片”和“导出 PNG/JPEG”的关系不够直观；可编辑项目保存应明确标注，避免与分享图片混淆。

区域、窗口和全屏截图直接点击。其他操作最多展开一次子菜单；延迟截图直接列出秒数。最近截图点击直接打开，复制／保存／上传／置顶通过完整历史窗口操作。

“打开编辑器”承接状态菜单中的工具选择、撤销／重做和清空标注；这些动作继续由编辑器工具条及顶部应用菜单提供，不再占用状态菜单。无图片时“当前图片”禁用；识别子菜单中的框选识别仍可用。

快捷键显示附在区域截图项目旁；注册失败用可点击的“快捷键不可用…”提示进入配置窗口，错误状态允许多一行。移动菜单不新增重复快捷键注册，也不改变用户保存的全局快捷键。

## 顶部菜单调整

| 菜单 | 建议职责与分组 |
| --- | --- |
| CaptureLab | 关于、设置入口、检查更新、系统隐藏／退出。设置归组，Command-comma 继续进入现有截图设置窗口；本轮不新建复杂的统一设置界面 |
| 文件 | 打开图片、打开项目、添加图片到画布；保存 PNG、导出 PNG/JPEG、保存可编辑项目；分享子菜单提供复制图片、上传到 R2 |
| 编辑 | 保留系统文本剪切／复制／粘贴；图片粘贴、撤销／重做、多选、清空标注归入这里。文本框粘贴仍优先使用原生行为 |
| 截图 | 区域、窗口、全屏、上次区域；更多方式子菜单提供冻结、3 秒、5 秒、统一入口。移出打开、保存、上传及识别语言设置 |
| 工具 | 选择、裁剪；“线条与形状”（箭头、曲线箭头、直线、矩形、椭圆、实心矩形）；“文字与标记”（文字、计数器、画笔、高亮）；“视觉处理”（马赛克、模糊、聚光灯）；“文字与二维码”识别操作 |
| 窗口 | 打开编辑器、查看历史及系统窗口管理；状态菜单中的浮层与贴图管理仍始终可达 |

工具菜单由 20 项一级项目收缩为约 6 项。快捷键保持现有绑定，分组不改变标注类型或功能。必要跨表面的入口（例如状态菜单和顶部“截图”）共用动作；同一表面内部去除重复。

## 0.11.0 实施边界与验收

菜单整理已按此方案完成。状态菜单已从 33 个一级入口收缩为 13 个，顶部“文件／截图／工具”菜单已完成职责分组和重复入口收敛；旧清单保留用于说明调整前的基线。

- 已落实状态菜单 33 → 13 项、“文件／截图”重复入口整理及工具与设置分组。
- 保留每个现有功能的可达路径、用户快捷键、中文版与英文版。正常菜单最多两级。
- 验证空文档／有图／正在截图／识别中／上传中／更新中的可用状态，防止分组后误启用操作。
- 验证菜单的键盘导航、现有快捷键、文本框粘贴、从菜单打开编辑器和历史、鼠标穿透贴图的解锁入口。
- 菜单排版在原生菜单中检查，不再次引入滚动截图或对第三方应用的滚动兼容验收。
