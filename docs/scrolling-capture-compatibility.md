# 滚动截图兼容性与验收记录

记录日期：2026-10-03。属于用户确认合并实施的 0.9.0 范围。本文区分自动化证据、设计边界与尚未执行的实机验收，不以合成图通过推定实际应用兼容。

## 使用与明确边界

从纵向或横向滚动截图入口启动后，在同一个应用窗口、同一个显示器内框选滚动内容。初始状态暂停；如有固定顶部／底部（横向时为左侧／右侧），先按**截图源像素**填写宽度并应用，再继续。每次只向下或向右滚动，至少保留 25% 重叠，滚动后短暂停顿。捕获间隔至少 700 毫秒，并等待上一帧匹配完成；不模拟用户滚轮、不要求辅助功能权限、不生成录像或 GIF。

控制面板显示已接受长图的缩略预览；低置信度时暂停，显示未加入的候选画面。可输入“新增像素”手动接受候选接缝，或修改最后已接受接缝；也可丢弃最后一段，再回滚至相应位置继续。结束只输出已接受的内容，取消丢弃本会话。固定边栏只出现一次；其它方向的侧栏、滚动条应在框选时排除。

每次会话方向固定，不支持跨屏、任意二维平移、自动滚动、检测无限页面的“结束位置”。手动纠正代表用户接受接缝；内容本身完全重复且像素相同，无法仅通过图像判断是否真的滚动。小面积光标闪烁可被视为重复帧；大面积刷新、动画、重新排版可能暂停或匹配失败。

移动／缩放／关闭目标窗口、目标被另一普通窗口遮挡、显示器配置变化、权限丢失或超过 10 分钟，会停止采集并保留已接受图像供结束。与滚动速度过快无法区别的内容刷新统一提示“无法找到可靠重叠”，不会自动接受该帧。当前画面匹配有抽样和密集复核，不承诺检测所有局部动态变化。

## 图像资源预算

- 源画面至少 96 × 96 像素，最多 1200 万像素；结果单边最多 32768 像素，最多 4000 万像素。
- 384 MiB 的图像预算包含为重复撤销保留的源帧、候选与转换余量，以及两份最终图像空间；超过预算前拒绝添加，保留已有结果。它不是整个应用进程 RSS 的硬上限。
- 每帧匹配在独立 actor 上执行；循环定期检查取消。预览最长边最多 900 像素，直接将各段绘到小画布，不为每次预览反复合成完整长图。
- 只在“结束”时合成完整图像，随后释放本会话帧，交给现有编辑／历史／项目／PNG／R2 路径。下游大图编辑和上传还受已有模块自身的限制。

## 自动化验收

`Tests/CaptureLabTests/ScrollingCaptureTests.swift` 覆盖：

| 场景 | 验证内容 |
| --- | --- |
| 已知完整像素序列，纵向与横向 | 每个像素与完整基准相同，输出尺寸精确，未漏行／重行／翻转 |
| 两端固定边栏 | 保留一次边栏，滚动内容接缝精确 |
| 抗锯齿文字页面 | 原始文字像素不变，非整行滚动后的接缝精确 |
| 重复帧 | 不追加、不增长、不增加帧保留 |
| 反向／无重叠／内容刷新／尺寸变化 | 拒绝候选且已有结果不变 |
| 重复纹理 | 拒绝不确定自动接缝，允许手动选择已知接缝 |
| 手动接缝与重复撤销 | 修改最后一段、恢复匹配参考帧、再次继续 |
| 无效边栏／无效接缝 | 无效操作不改变已接受图像 |
| 单边／像素／图像预算 | 添加前失败并保留已有结果 |
| 缩略图／worker 清理 | 预览尺寸有界，清理后无法输出上次会话图像 |

以上 13 项算法／窗口筛选测试不验证真实屏幕录制权限交互、触控板惯性、WindowServer 图像获取、多屏热插拔或全屏 Space。WindowServer 的独立验收如下。

## WindowServer 原生合成窗口实测

2026-10-03 已执行 `ScrollingCaptureWindowSmokeTests.swift` 的 fixture v1：自建 AppKit `NSScrollView` 窗口，使用原生等宽抗锯齿文字与彩色单元格，只捕获测试自己创建的窗口。环境为 **macOS 27.0.1（26A434）、arm64、AppKit 2775.1、Xcode 27.0（27A266a）／Swift 6.4**；屏幕逻辑尺寸 3008 × 1692 pt，截图 backing scale 为 2。fixture 属于 CaptureLab 0.9.0 工作树中的测试程序，没有 Safari／Chrome 等第三方应用版本。

| 方向 | 视口 | 滚动步幅 | 输出与扩大窗口的参考截图 | 结果 |
| --- | --- | --- | --- | --- |
| 纵向 | 340 × 260 pt／680 × 520 px | 83 pt／166 px | 680 × 686 px | 所有 RGBA 像素完全相等 |
| 横向 | 340 × 260 pt／680 × 520 px | 83 pt／166 px | 846 × 520 px | 所有 RGBA 像素完全相等 |

两项测试让真正的 `NSScrollView` 滚动，读取 WindowServer 图像、自动匹配并拼接，再与同一原生窗口扩大后的完整参考图比较；固定边栏值均为 0。未使用逐像素容差，也未裁去接缝或文字。fixture 统一为 sRGB、layer-backed 绘制，并在第一次取图前往返预热两个滚动方向后复位：AppKit 首次初始化滚动 surface 时会使部分文字色值改变 1–3，预热保证基准与滚动后的截图采用相同绘制路径。此约束属于测试基准；实际应用中重新绘制、色彩转换或动态内容仍可能产生像素差异。

最终命令如下；默认不设置 `CAPTURELAB_SCROLLING_WINDOW_SMOKE=1` 时，这两项测试跳过，不应计为实测通过：

```sh
CAPTURELAB_SCROLLING_WINDOW_SMOKE=1 \
CAPTURELAB_SCROLLING_WINDOW_OUTPUT=/tmp/capturelab-scrolling-review-final-artifacts \
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
swift test --scratch-path /tmp/capturelab-scrolling-review-final \
  -Xswiftc -strict-concurrency=complete \
  --filter 'ScrollingCaptureTests|ScrollingCaptureWindowSmokeTests'
```

本次最终结果 **15 项通过、0 失败、0 跳过**（13 项算法／窗口筛选 + 2 项真实 WindowServer fixture）。本机日志保存在 `/tmp/capturelab-scrolling-review-final.log`，8 张合成内容 PNG（每方向的首帧、次帧、拼接图、参考图）在 `/tmp/capturelab-scrolling-review-final-artifacts`，不含桌面或其它应用内容，不作为仓库资源提交。

这两项仅验证静态原生合成内容在本机 2× 显示环境的截图与拼接，没有经过产品的框选／控制面板完整交互，不覆盖屏幕录制权限弹窗、真实滚轮／触控板惯性、窗口遮挡与移动中断、多屏切换或第三方应用。不能据此把下面的实际应用清单认定为通过。
