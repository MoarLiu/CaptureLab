| 标注样式 | 箭头样式、形状描边／填充、字体／字重／对齐／文字背景／边框；高级样式面板保存／应用／删除样式，收藏颜色 |
| 笔迹与高亮 | 画笔平滑；本地 Vision 识别文字区域并辅助对齐高亮，仍可手动移动／缩放；迟到识别结果不改变新文档 |
| 多图组合 | 粘贴、拖入和“添加图片”保留独立资源；图层画布支持多选、组合移动、缩放、旋转、复制、删除、图片层级、对齐、等间距和横向／纵向排列 |

编辑器底部切换“标注／图层／预览”。添加的图片位于标注下方，遮挡统一作用于图片组合；图片可相互调整层级。背景在裁剪与尺寸变换后的合成图周围布局，不改变源对象坐标。复制、PNG 拖出、保存、置顶、历史及 R2 输出共享合成流程；R2 继续上传 PNG。

## 文档与资源约束

- 项目格式升级为 2，内嵌源图、独立图片资源、全部标注样式、几何信息及背景布局；不写入导入路径。可读取格式 1；旧客户端遇到格式 2 会提示更新。
- 新增对象、组合操作、布局变更都进入文档撤销／重做；项目／历史重开后保持可编辑。持久化当前状态，不保存完整撤销栈。
- 最多添加 32 张图，添加图片累计最多 128 MiB／一亿像素；项目总文件最多 192 MiB。导入失败保留当前画布。批量拖入在读取过程中检查累计体积，超限即停止。
- 除尺寸和元数据外，还检查图片资源能否建立解码图像，拒绝只有合法 PNG 头部而无图像数据的项目与背景。
- 滚动源帧至少 96×96、最多 1200 万像素，结果单边最多 32768、最多 4000 万像素；384 MiB 图像预算与最长边 900 像素预览，详见[兼容记录](scrolling-capture-compatibility.md)。
- 项目仍包含遮挡下的原始像素；普通分享只输出合成图片。模糊是视觉效果，不替代马赛克。

## 本轮收尾修复

- 图片靠近画布边缘时，旋转／缩放手柄可见且可命中，拖动允许经过画布外部；变换结果仍受有效尺寸限制。
- 多图片副本保留真实层级，避免存储顺序与 z 顺序不一致时前后颠倒。
- 曲线控制点与端点重合时使用有效极限切线，双端箭头方向一致。
- 保留旧格式原本合法的大字号／线宽；输出尺寸或旋转使背景超限时拒绝且不增加撤销记录。
- 修复中间图像缓存导致马赛克未进入输出的问题；模糊与马赛克使用当前合成栈，失败不退回原图。
- 粘贴前提交尚未完成的文字编辑；背景面板不会将旧文档草稿应用到已替换文档。
- 最近导出尺寸按当前图片比例重算；取消的旧预览不覆盖新预览或错误提示，损坏背景提供明确修复信息。
- 滚动框选 Esc 和会话取消都恢复窗口、保留当前编辑与剪贴板；失败后可继续下一次截图。

## 验证

使用完整 Xcode，严格并发和警告作为错误：

```bash
CAPTURELAB_SCROLLING_WINDOW_SMOKE=1 \
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
swift test --scratch-path /tmp/capturelab-090-final \
  -Xswiftc -strict-concurrency=complete -Xswiftc -warnings-as-errors
```

- 完整测试 **365 项全部通过，0 失败、0 跳过**，相对 0.8.0 的 290 项新增 75 项；日志 `/tmp/capturelab-090-final.log`。最终完成时间 2026-10-03 02:02（北京时间），本轮无编译警告。
- ARM64／x86_64 Release 构建已通过相同编译检查；主程序及更新辅助程序的 Mach-O 架构、最低 macOS 13.0 已核验。日志 `/tmp/capturelab-090-arm64.log` 和 `/tmp/capturelab-090-x86_64.log`。
- 原生编辑器的最小宽度 1080 点、图层视图、输出预览、高级文字样式、图层面板、背景与导出面板已用纯合成素材渲染并检查。截图 `/tmp/capturelab-090-ui/`，无用户截图或本地文件内容。
- 原生事件覆盖图层拖动、边界手柄、缩放旋转、多选、键盘移动、Esc 取消；集成覆盖项目升级、损坏资源、旧字号、背景超限、撤销、历史重启、分享像素一致性及批量导入原子性。
- 滚动专项 15 项通过：13 项算法／窗口筛选，加 2 项真实 WindowServer 纵横原生滚动窗口。2× 视口为 680×520，步幅 166 像素；结果为 680×686／846×520，与扩大原生窗口参考图所有 RGBA 像素完全相同。
- WindowServer 测试先预热原生滚动表面，避免首帧初始化造成颜色量化差异；保留严格逐像素断言，没有放宽容差。
- `git diff --check`、构建／打包脚本 Bash 语法检查通过；变更文件扫描未发现私钥或实际凭据。测试素材与构建产物留在 `/tmp`，未加入项目源文件。

## 实机验证与发布边界

- 当前验证环境为 Apple Silicon、macOS 27.0.1（26A434）。没有真实 Intel／macOS 13、多屏混合缩放或全屏 Space 的运行结果。
- 原生滚动窗口是测试自己的合成 fixture，不代表 Safari／Chrome、聊天应用、代码编辑器全部兼容；[兼容清单](scrolling-capture-compatibility.md)明确区分已通过项与待验收项。
- 产品完整框选与真实滚轮惯性、录屏权限弹窗、跨 Space、窗口遮挡／移动的完整手工流程，以及长时间大项目编辑仍待实机验收。
- 未进行真实 R2 上传、物理 Intel／macOS 13 运行或端到端自动更新验收。发布准备与当前确认状态见下节。
