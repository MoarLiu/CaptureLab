# CaptureLab 0.12.0 发布验收记录

日期：2026-10-24。基线：`0.11.2 / 534be3f`。准备分支：`codex/0.12.0`。目标：**0.12.0，构建 19，标签 `v0.12.0`**。Release 标题：`CaptureLab 0.12.0`。

状态：本地发布准备与核验完成，用户已于 2026-10-24 最终确认发布。远端发布状态以 [GitHub Release](https://github.com/MoarLiu/CaptureLab/releases/tag/v0.12.0) 为准。本记录与 [开发验证](0.12.0-validation.md)、[交互规范](0.12.0-ui-ux-spec.md) 一同维护。

## 交付范围

- 原生菜单栏工具：图标、真实快捷键列、任务分组，以及按资源显示的浮层／贴图恢复入口。
- 单一设置窗口：通用、快捷键、快捷浮层、上传和关于；就地录制、注册状态、历史保留确认、上传草稿及关闭保护。
- 自由区域截图默认松开完成，不显示比例／尺寸面板；精确框选保留主动调整。
- 编辑器压缩常规顶部，仅在标注／裁剪时显示属性行；图层开关、背景和结果操作集中，样式及图片调整按需进入。
- 识别五种状态和重新框选、正确启动器说明、统一重复操作成功反馈、准确的密钥复用与更新忙碌说明。
- 保存图片直接进入系统面板，复制并关闭保留恢复保护；导出不沿用另一图片的尺寸，背景预设优先。

现有项目、偏好与 Keychain 身份保持兼容。R2 请求签名和传输实现未改动，沿用用户先前手动验证的可用通道；本轮使用模拟凭据验证配置和导航，不发起真实账户上传。

## 构建与检查

- 完整 Xcode 下 `./script/verify.sh --scratch-path .build/0120`：**410 项通过，0 失败、0 跳过**，严格并发及警告作为错误。
- 随后修正英文最小窗口的工具图标裁切；最终源码通过 16 项界面回归、4 项英文编辑器回归，以及 ARM64／x86_64 主程序和更新辅助程序严格 Release 构建。全部构建目标 macOS 13.0，架构及 Mach-O 最低版本已核对。
- 设置五个分类在中英文、900×640／760×540、浅色／深色和 NSAppearance 增强对比度下检查；编辑器覆盖 900×600 的选择／标注／裁剪及常用面板。识别覆盖未开始、进行中、失败、无结果和结果。
- 源码隐私扫描没有真实凭据、私钥、个人绝对路径、用户历史或运行状态。匹配仅为合成拒绝路径、恶意 URL 测试和图标文件名。唯一大于 1 MiB 的源码资源是原有图标；四张第三方参考图仅属于设计文档，不打入应用。
- 包内仅五个文件：Info.plist、主程序、更新辅助程序、图标和签名资源。卷根只有应用和 Applications 链接；无测试 fixture、用户数据、AppleDouble、私钥或源码绝对路径。
- 双架构均通过 DMG 校验、SHA-256、Ed25519 更新签名、只读挂载、复制字节一致性、版本 0.12.0／19／最低 macOS 13 和指定身份签名验证。
- 启动验证使用安装副本和每进程显式临时 HOME，按 PID 核对可执行文件路径；不替换正式安装或终止用户既有进程。两种启动方式均正常退出，启动日志仅含系统保存状态隔离说明，没有应用错误。
- `git diff --check`、验证／打包脚本 Bash 语法检查通过。测试、日志、启动状态与安装副本均留在忽略的 `dist/validation-0.12.0/`；源码提交使用明确文件清单。

## 签名与覆盖边界

沿用固定本地自签名身份及现有 Ed25519 更新密钥，未启用 Hardened Runtime、未公证、无额外 entitlements。Gatekeeper 评估拒绝，首次打开可能需要用户手动批准；不声称通过 Gatekeeper。

本机为 Apple Silicon／macOS 27.0.1，Intel 启动使用 Rosetta；物理 Intel、macOS 13、多显示器混合缩放、热插拔、全屏 Space、完整 VoiceOver／系统减少透明度操作及从 UI 开始的完整更新安装仍为人工与环境保留项。NSAppearance 模拟不替代完整辅助功能实机验收。开发计划 A10、A11 继续保持部分覆盖。
