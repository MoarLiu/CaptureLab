# CaptureLab 0.10.1 Release Validation

Date: 2026-10-03. Baseline: `main @ 1076c9d` (0.10.0).
Target: 0.10.1, build 15, tag `v0.10.1`.
The user confirmed publication on 2026-10-03. This record describes the
pre-publication validation; the published state is available on the
[GitHub Release](https://github.com/MoarLiu/CaptureLab/releases/tag/v0.10.1).

## Review

- Mouse release uses its final window-to-screen coordinates, completes the
  selection once, and closes the selector through the existing validated finish
  callback. Empty clicks do not capture. Invalid or oversized selections keep
  the existing validation error. Escape, right-click, and keyboard confirmation
  retain their existing paths.
- The editor workflow copies the new document's original image before its new
  history entry and editor presentation. Existing-document recovery remains a
  prerequisite. Later annotations do not change the clipboard snapshot.
- The zoom menu has one native indicator and a fixed 56 by 28 point layout.
  Native hit tests cover Fit, 50%, 100%, and 200%; clicks immediately outside the
  menu reach the window-drag region.
- The existing default quit callback now explicitly uses the main actor,
  removing ordinary-build concurrency warnings without changing quit ordering.
- No remaining release-blocking issue was found in the intended changes.

## Validation

- A fresh scratch build ran the complete test suite with
  `-strict-concurrency=complete -warnings-as-errors`. The final version and
  callback annotation were then revalidated: 389 tests, zero failures and skips.
- Both real WindowServer scrolling fixtures passed exact pixel comparisons.
- ARM64 and x86_64 Release builds use the same strict flags and target macOS 13.
  Repository packaging scripts completed without compiler warnings.
- Both read-only mounted DMGs have version 0.10.1, build 15, the expected
  architecture and deployment target in the app and helper, and valid signatures
  tied to the existing certificate root and distinct bundle identifiers.
- SHA-256 sidecars and Ed25519 update signatures match the final DMGs. Mounted,
  packaged, and smoke-test copies have identical file contents.
- Bundles contain only executables, Info.plist, the existing icon, and signature
  resources. No private keys, local build paths, user data, test fixtures, logs,
  or AppleDouble files are included. Source privacy matches are synthetic test
  values, implementation fields, or public signing identities.
- ARM64 and Intel startup used isolated data directories, completed AppKit
  launch, had empty startup logs, and exited through normal application quit
  requests. Intel startup used the installed Rosetta runtime on this host.
- Build, test, signature, manifest, and startup records are kept in ignored
  `dist/validation-0.10.1/`. Source diff and shell syntax checks passed.

## Limits

Signing uses the existing self-signed identity, without notarization or hardened
runtime. Gatekeeper assessment rejects both bundles; first launch may require
manual approval. Rosetta startup is not physical Intel or macOS 13 validation.
Mixed-scale multi-display dragging, full-screen Spaces, and manual desktop
capture remain unverified. Automated capture checks use synthetic fixtures.
