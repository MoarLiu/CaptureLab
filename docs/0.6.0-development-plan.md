# CaptureLab 0.6.0 开发与验证记录

日期：2026-10-02。开发分支：`codex/0.6.0`。版本：`0.6.0`，构建号：`10`。

功能实现完成；本记录区分自动化／界面验证与仍待人工验收的项目。尚未封版或发布。

## 已实现范围

### 截图完成后的操作

- 提供直接编辑、快捷浮层、仅复制三种模式；默认继续沿用直接编辑。
- 浮层和仅复制模式会复制结果、记录历史，同时保留当前文档、标注、撤销记录和 OCR 内容。
- 浮层支持复制、保存、编辑、置顶、R2 上传、拖出、关闭、多结果翻页、暂时隐藏和恢复最近关闭项。
- 可配置四角位置、280／320／400 点宽度、永不或 5／15／30／60 秒后自动关闭，以及跟随捕获结束时鼠标所在显示器或使用主屏幕。
- 悬停、拖动和截图期间暂停自动关闭；截图时隐藏浮层，完成后恢复。
- 浮层操作绑定不可变 PNG 快照，切换文档、裁剪或删除历史不会替换操作对象。内存中的结果受数量和字节预算约束，历史记录独立保留。

### 图片输入和输出

- 编辑器和菜单提供“粘贴图片”；非文本编辑状态下支持 Command-V，文字输入框继续处理文字粘贴。
- 支持图片数据及本地文件 URL 拖入，作为独立文档打开；迟到的加载结果不能覆盖更新的文档或导入请求。
- 替换已编辑或导入的图片前，将其合成结果保存到历史；失败则保留原文档及撤销状态。历史再次打开仍是合成图片，可编辑项目将在 0.8.0 实现。
- 编辑器、历史卡片及浮层提供手形拖出入口；通过系统文件承诺交付合成 PNG，并提供 PNG 剪贴板表示。
- 文件承诺自行持有固定数据；源窗口关闭或历史变化后，接收方仍能获取同一份内容，不依赖提前删除的临时文件。
- 保存对话框期间切换文档时，历史备份复用已冻结的渲染结果；重新打开当前历史项时先保存编辑，避免读回过时像素。

### 置顶贴图

- 锁定后开启鼠标穿透。
- 未锁定时，方向键移动 1 点，Shift 加方向键移动 10 点。
- 菜单栏提供解锁全部和关闭全部；原有缩放、透明度、Esc 和 Command-W 保留。

### 历史保留

- 数量选项为 30／100／300；期限选项为不按时间清理／1／7／30 天，先达到的限制生效。
- 设置与历史索引放在同一次原子写入中，使用既有进程锁；旧索引使用默认策略。
- 清理前显示受影响数量；确认期间若其他实例新增截图，导致需要删除额外记录，会重新确认。
- 磁盘写入失败保留原记录；写入已完成但随后报告失败时，重新读取磁盘状态，避免内存和文件错位。
- 时间清理在启动、截图和历史刷新时执行；已另存到其他位置的图片独立于历史保留策略。

## 实现结构

- `CaptureWorkflowSettings` 保存截图后行为与浮层偏好。
- `CaptureQuickAccessController` 管理浮层结果、选择、窗口位置和计时。
- `CaptureImageTransfer` 负责导入校验、不可变快照、图片粘贴及 PNG 文件承诺。
- `CaptureWorkflowSettingsView` 集中展示偏好与历史保留设置。
- 现有视图模型负责截图结果分发和恢复保存；历史存储负责原子策略变更。
- 新增 `CaptureWorkflowTests` 和 `CaptureHistoryRetentionTests`，共 21 项测试。

## 提前开展的滚动截图原型

独立脚本 `experiments/scrolling_capture_probe.swift` 不参与应用构建。它提供手动采样、两帧偏移匹配及可选的 PNG 拼接输出。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift experiments/scrolling_capture_probe.swift --self-test

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift experiments/scrolling_capture_probe.swift \
  --compare first.png second.png vertical stitched.png
```

合成样例结果：纵向 57 像素和横向 42 像素位移识别正确，拼接结果与完整生成图逐像素一致；固定顶部区域样例通过，重复帧识别为零位移，重复纹理被标为歧义而拒绝自动拼接。

这只是可行性验证。真实网页、原生列表、聊天和代码编辑器的兼容性、动态内容、反向滚动、长图内存管理及完整交互仍待 0.11.0 阶段展开。应用没有开放滚动截图、录屏或 GIF 入口。
